## 1. 世界觀

- 架空的中華風王朝「**昭國**」，都城「**鳳京**」。年代感約唐宋之間，沒有真實的歷史人物或事件。
- 三個舞台：
  - **後宮**：皇帝的妃嬪與宮人居住的內廷，由「掖庭」管理宮人。
  - **花街**：鳳京南城的煙花巷「**柳巷**」，最大的妓樓是「**錦鯉樓**」。
  - **宮廷外**：鳳京城內的市集、貧民區、酒坊、藥鋪。
- 藥學設定：太醫署負責宮中醫事；民間藥師的知識有時比太醫更實際，這是主角能發揮的空間。

### 1.1 開場：陰錯陽差入宮

- 卯卯在柳巷旁的農村長大，被老藥師杜衡收養，平常幫杜衡送藥到錦鯉樓。
- 某天宮中來採選下女。名冊上寫的是隔壁農家的女兒「卯娘」，但名冊被雨淋糊，又剛好碰上卯卯送藥經過，就被誤認帶走。
- 進宮後卯卯沒有聲張：一來說了也沒人信，二來**後宮的藥庫有民間看不到的藥材**。她打算低調做滿年限再回去。

## 2. 核心循環

```
委託（開場劇情）
  → 調查（場所／查看點／問話，消耗時辰）→ 線索卡
  → 鑑定（圖鑑篩選，易混群組）          → 藥材卡
  → 試藥／調藥（驗證、救人）            → 反應線索、證言
  → 推理板（臆測，可多次提交）
  → 指認（出示證物反駁辯解）
  → 結案（評價、事件全貌、獨語、解鎖）
```

## 4. 藥材圖鑑

### 4.1 資料結構

每種藥材一筆資料，由各類別檔案登記到同一個 registry（`PriTestYakushiHerbs.register(list)`），之後擴充只要新增檔案或條目，不改引擎。

```js
{
  id: "gouwen",               // 英數 id，唯一
  name: "鉤吻",
  alias: ["斷腸草", "胡蔓藤"],
  cat: "poison",              // 6 類之一（§4.2）
  group: "yellow_vine",       // 易混群組 id（§4.4），可為 null
  traits: {                   // 鑑定用特徵（§5.1 的勾選項目）
    form: ["藤本", "黃花", "漏斗狀花冠", "葉對生光滑"],
    smell: ["無明顯氣味"],
    taste: [],                // 毒物的味道欄可空；嚐毒有代價（§5.2）
    symptom: ["呼吸困難", "肌肉無力", "眩暈"],
    onset: "fast"             // fast（一刻內）／mid（數時辰）／slow（數日以上）
  },
  tests: { heat: null, silver: null, water: null, animal: "雞食後很快站不穩" },
  distinguish: "與金銀花同為黃花藤本；金銀花花成對、黃白兩色並有清香，鉤吻無香、花冠漏斗狀。",
  remedy: null,               // 遊戲內解方 id 陣列，沒有就 null
  lore: "……",                 // 圖鑑說明（常識程度）
  danger: 3                   // 0 無毒～3 劇毒，用於圖示與嚐藥代價
}
```

- 每個群組的每個成員，**至少要有一種方法能和同群組的其他成員分開**（由檢查腳本確認，§10）。

### 4.5 安全原則（藥材文字）

- 只寫**常識程度**的知識：外觀、氣味、症狀、歷史用途、遊戲內的分辨方式。
- **不寫劑量、提煉、取得方法**。
- 遊戲內的「解方」是遊戲用的抽象規則，標註「遊戲設定，非醫療建議」。
- 圖鑑頁底部固定顯示免責文字。

## 5. 鑑定、試藥與調藥

### 5.1 鑑定（特徵比對）

1. 對證物或病人「觀察」，取得特徵標籤，例如「紫色小花」「口唇發麻」「一刻內發作」。
2. 打開圖鑑，勾選已取得的特徵，候選藥材即時縮減。
3. 選定一種後，「鑑定完成」，得到該藥材的「藥材卡」。
4. **鑑定錯誤不會立刻提示**：會得到錯誤的藥材卡，並消耗 1 時辰；等到推理板或指認時才會出現矛盾。
5. 候選剩下同一個易混群組時，介面提示「這幾種很像，需要再驗證」。

### 5.2 試藥（驗證）

對證物使用驗法，得到「反應線索」。每次試藥消耗時辰（暫定 1）。

| 驗法 | 用途 |
|---|---|
| 細看 | 切面、花、種子、根的形狀 |
| 嗅 | 香氣、臭味 |
| 嚐 | 最準，但對 `danger ≥ 2` 的藥材有代價：卯卯「體力」-1（體力歸零就強制休息，消耗 2 時辰）。卯卯會想嚐，這也是她的個性笑點 |
| 銀針 | 只對含硫雜質的砒霜變黑；對其他毒無反應（教學時會說明） |
| 溶水 | 溶解與否、顏色、沉浮 |
| 加熱 | 煙、氣味、顏色變化 |
| 餵動物 | 用雞或鼠觀察反應與發作時間 |

### 5.3 調藥（救人）

- 案件中可能出現仍在發作的病人。
- 從藥箱選 1～3 味藥材組成解方，系統比對案件資料中的「有效組合」。
  - 對了：病人好轉，並得到該人的證言線索。
  - 錯了：病況惡化一級，消耗 1 時辰；惡化到底會被太醫接手，失去這條證言（不會失敗）。
- 解方只在遊戲內有效，見 §4.5。

## 6. 調查與時辰

- 每案有「時辰」額度（序章 8、案 1～3 為 12，暫定）。
- 行動成本（暫定）：移動到場所 1、查看點 1、問話 1、試藥 1、鑑定錯誤 +1、調藥錯誤 +1。
- 時辰用完：卯卯被叫回去，強制進入推理板；手上的卡可能不夠，但仍可以推理與指認（評價較低）。
- 每個場所有 2～4 個查看點與問話對象；問話可以有分支選項，選錯不扣分，只是浪費時辰。

## 7. 推理板與指認

### 7.1 推理板（臆測）

- 4 個格子：**誰／用什麼／怎麼下手／為什麼**。玩家把線索卡或藥材卡放進去。
- 「提交臆測」：只回饋「4 格中有幾格正確」，不說哪一格錯。提交次數計入評價。
- 4 格全對才能進入指認。
- **深層臆測格**（只在有深層謎團的案件出現）：可選填，沒有正解，不影響評價；放進不同的卡會改變結案時的「獨語」（§8）。

### 7.2 指認

1. 對犯人出示推理。犯人辯解 2～3 輪（依案件資料）。
2. 每輪要出示一張能推翻該辯解的卡片。
3. 出示錯誤扣「信任」1（初始 3，暫定）；信任歸零 → 指認失敗，可從指認重來（評價降一級）。

### 7.3 評價

依剩餘時辰、臆測提交次數、指認失誤次數計算 S～C（公式暫定，放 `yakushi_core.js` 的常數）。

## 8. 劇情：表層真相與留白

- **表層真相**：每案都有。指認成功後，以「事件全貌」劇情完整敘述推理過程：誰在何時用什麼、為何如此、每條線索如何對上。
- **深層謎團**：部分案件有，沒有正解。
  - 結案時卯卯的「獨語」會依深層臆測格的內容變化，遊戲不證實也不否定。
  - 所有獨語收在「**獨語帖**」，可以回頭重讀；同案的不同獨語也會收錄（重玩收集）。

## 9. 案件大綱（第 1 階段）

### 9.0 序章「芋頭與名冊」（教學）

- **舞台**：下女宿舍。時辰 6。
- **事件**：入宮第三晚，宿舍晚飯後多名下女口舌發麻、喉嚨腫痛。秦尚宮懷疑有人下毒。
- **教學內容**：查看點、問話、鑑定、試藥（嚐、細看）、調藥、推理板、指認全部走一次。
- **線索**：剩下的「芋頭」切面、廚房帳本、採買小宦官的證言、病人症狀。
- **鑑定**：`raw_tuber` 群組 → 生半夏。
- **調藥**：生薑（遊戲內有效）。
- **正解**：誰＝採買的小宦官；用什麼＝生半夏；怎麼下手＝冒充芋頭混入食材；為什麼＝買便宜的野生塊莖，私吞差價。
- **結局**：沒有惡意，只是貪小便宜。玄氏注意到卯卯，結尾第一次登場。

### 9.1 案 1（後宮）「沉香夜話」

- **舞台**：梁昭儀的宮殿、香料庫、太醫署、宮女住處。時辰 12。
- **事件**：梁昭儀連日失眠、心悸，夜裡看見幻影；周太醫診斷為「心神失養」，越治越糟。玄氏命卯卯暗中調查。
- **線索**：寢殿香爐的灰燼、香料庫的入庫帳、同鄉女官送的「沉香」、昭儀口乾與瞳孔放大的症狀、侍女證言。
- **鑑定**：
  - `fragrant_wood` 群組：送來的「沉香」入水會浮，是檀香冒充的。
  - `nightshade` 群組：香裡混了花粉，看種子形狀，是曼陀羅。
- **調藥**：昭儀發作中，正確解方可以讓症狀減輕並取得證言（遊戲內解方）。
- **正解**：誰＝昭儀的同鄉女官；用什麼＝摻入曼陀羅花粉的假沉香；怎麼下手＝以「家鄉送來的好香」名義每晚點燃；為什麼＝昭儀把女官的心上人調離京城，女官懷恨在心。
- **深層（留白）**：假沉香的包裝紙來自更高位妃嬪宮中的香料鋪。女官到最後都不肯說是誰教她混花粉的。深層臆測格可放「某妃嬪／女官自己／香料鋪」等卡片，各自對應不同的獨語。

### 9.2 案 2（花街）「錦鯉樓的苦杏」

- **舞台**：錦鯉樓（宴廳、廚房、雪鵑的房間）、柳巷、杜衡的藥鋪。時辰 12。卯卯藉「回家探視養父」出宮，韓當隨行。
- **事件**：鹽商在雪鵑的宴席上猝死。官差懷疑雪鵑端上的杏仁茶有毒，葛婆怕樓被封，把卯卯叫回來。
- **線索**：剩下的杏仁茶、酒壺、廚房的杏仁袋（甜杏仁）、鹽商帳房的證言、債務字據、試喝剩酒後不適的小丫頭。
- **鑑定**：
  - `almond` 群組：茶裡用的是甜杏仁，清白。
  - 酒壺裡有苦杏仁搗碎後的特殊氣味，要用試藥（餵動物、嗅）確認。
- **調藥**：小丫頭症狀輕，用正確的遊戲解方照護後，可以取得「是誰送酒來」的證言。
- **正解**：誰＝鹽商的帳房；用什麼＝苦杏仁搗汁；怎麼下手＝以「主人愛喝的家鄉酒」為名送進宴席，嫁禍給杏仁茶；為什麼＝帳房挪用公款，怕鹽商查帳。
- **指認辯解**：「茶裡就有杏仁」→出示甜杏仁鑑定；「酒我沒碰過」→出示小丫頭證言；「我與老爺情同父子」→出示債務字據。
- **深層**：無。結尾雪鵑、月棠、緋桐與葛婆的日常戲，以及杜衡看著卯卯欲言又止（杜衡過去的伏筆）。

### 9.3 案 3（宮廷外）「端午的黃酒」

- **舞台**：鳳京北市、貧民區、酒坊、藥鋪、市集官署。時辰 12。
- **事件**：端午前後，北市貧民區接連有人嘔吐、腹痛、手腳發麻，謠傳是疫病，官府準備封街。玄氏要卯卯在封街前查清楚。
- **線索**：病人共同喝過的「御用雄黃酒」、酒坊的進料（劣質雄黃）、酒罈上的御用封印、藥鋪掌櫃證言、加熱過的酒渣。
- **鑑定與試藥**：
  - `red_mineral` 群組：酒裡的是雄黃。
  - 加熱試驗：劣質雄黃經溫酒加熱後產生有毒物質（遊戲內以「加熱→白煙、蒜臭」呈現）。
  - `white_powder` 群組：銀針反應要配合其他驗法才能確定，示範「銀針不是萬能」。
- **調藥**：輕症病人用遊戲內解方（例：綠豆、甘草）照護，取得證言。
- **表層正解**：誰＝酒坊老闆；用什麼＝劣質雄黃；怎麼下手＝溫熱後大量販賣廉價的「御用」雄黃酒；為什麼＝節省成本、假冒御用招牌賺錢。
- **深層（留白，主線引子）**：
  - 酒罈上的御用封印是**真的**。
  - 案件結案後，玄氏立刻下令封存封印證物，不准再查。
  - 深層臆測格可放「宮中有人流出封印」「玄氏在包庇某人」「玄氏在保護卯卯」等卡片；遊戲不給答案。
  - 結尾卯卯的獨語：「……這件事，大概還沒結束。」
