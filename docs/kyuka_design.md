# 九華（kyuka）招募角色能力系統設計

> 狀態：**草案 v1（2026-11-16 依使用者指示整理）**。
> 這份文件定義「招募到的新人（女孩）」共通的能力資料，供冒險者公會及之後的各種小遊戲共用。
> 規則依據以這份文件為準；標示「暫定」的數值等試玩後再調整。
> 視覺參考：九華能力圖（Artifact，含櫻瓣花紋、九九八十一型一覽）。

## 1. 概要

- 每位新人＝**角色本體**（固定）＋**個體**（每次招募隨機）。
- 個體的核心是**九華 9V**：九項能力，每項 **1～99** 隨機。
- 9V 以**櫻瓣花紋**呈現：九片花瓣，花瓣長短＝數值，顏色＝所屬的三華。
- 稀有度分 **N／R／SR／SSR／UR**。稀有度越低，一開始看得到的花瓣越少，要靠**親密度**一片一片解鎖。
- 最高與第二高的兩項決定她的**型**（九九八十一型，§6）。
- 等級 **1～50**，升級時 9V 有機率微幅成長。
- 之後新增玩法時，以**標籤**擴充個體資料，不重抽 9V（§9）。

## 2. 角色本體（固定，同名角色都一樣）

| 欄位 | 說明 |
|---|---|
| 頭像、名字、個性設定 | 固定 |
| 稀有度 | N／R／SR／SSR／UR 之一 |
| 固有技能 | 角色的招牌能力，**難以變動**（只有好感達到最高時「覺醒」一次） |
| 性向 | 德 ↔ 惡 一條軸，與公會的惡名值連動 |

## 3. 九華 9V

### 3.1 九項與三華

九項分成三組，稱為「三華」。每組三片花瓣相鄰排列：

| 三華 | 九項（順時針） | 意義 |
|---|---|---|
| **魅** | 聲・美・瑟 | 嗓音／美貌（被欣賞）／色氣（主動撩撥） |
| **身** | 柔・速・剛 | 柔軟、閃避／敏捷／剛強、攻擊 |
| **心** | 心・智・緣 | 堅韌、抗壓（降低離隊）／聰慧／人緣與運氣 |

- 「美」在花紋正上方，魅占上方、身占右下、心占左下。
- 「美」與「瑟」是不同的能力：美＝被欣賞，適用於正式、公開場合；瑟＝色氣、誘惑，帶有引來麻煩的風險。

### 3.2 數值

- 招募時每項獨立隨機 **1～99**（均等分布）。
- 稀有度保底（**暫定**）：每項的最低值依稀有度提高，讓高稀有度不至於抽到極端低的個體。

| 稀有度 | 每項範圍（暫定） |
|---|---|
| N | 1～99 |
| R | 5～99 |
| SR | 10～99 |
| SSR | 15～99 |
| UR | 20～99 |

### 3.3 等級顯示

| 等級 | 數值 | 單項機率（N，1～99 均等） |
|---|---|---|
| S | 90～99 | 10.1% |
| A | 75～89 | 15.2% |
| B | 50～74 | 25.3% |
| C | 25～49 | 25.3% |
| D | 1～24 | 24.2% |

花紋上的同心虛線就是等級的分界。部分項目另有稱號（例：美 S＝傾國、瑟 S＝魔性、心 S＝不屈）。

## 4. 稀有度與花瓣的解鎖

一開始看不到的三華，花瓣以**含苞的灰色輪廓**顯示（數值、等級都不顯示），解鎖時播放花瓣綻放的演出。

| 稀有度 | 一開始可見 | 親密度 33 | 親密度 66 |
|---|---|---|---|
| N | 一華（三片） | 第二華 | 第三華（全部） |
| R | 一華（三片） | 第二華 | 第三華（全部） |
| SR | 兩華（六片） | 第三華（全部） | — |
| SSR | 全部 | — | — |
| UR | 全部 | — | — |

- 親密度範圍 0～100。
- **一開始可見的是哪一華**：該個體 9V 合計最高的那一華（讓玩家先看到她的長處）。SR 則是合計最高的兩華。之後依合計由高到低的順序解鎖。
- SR 第三華在親密度 33 解鎖（**暫定**，使用者只指定了 SR 一開始顯示兩邊）。
- 看不到的數值**照樣在遊戲中生效**，只是不顯示。
- **型名**（§6）要等九片全部可見後才顯示，在那之前顯示「？？」。型名揭曉本身就是親密度的獎勵。

## 5. 等級與成長

- 等級 1～50。升級需要的經驗值另訂。
- **每升 1 級，九項各自擲一次**，成功就 +1（上限 99）。成功率依稀有度：

| 稀有度 | 每級每項成功率（暫定） | 升滿 49 次的期望成長 |
|---|---|---|
| N | 15% | 約 +7 |
| R | 17% | 約 +8 |
| SR | 20% | 約 +10 |
| SSR | 22% | 約 +11 |
| UR | 25% | 約 +12 |

- 升滿等的成長屬於**微幅到小幅**：個體原本的 9V（抽到的好壞）仍是能力的主體，等級不會讓個體差異消失。
- 隱藏中的三華也會成長，解鎖時一併顯示。
- 成長可能改變最高與第二高的項目，因此型可能在升級後改變（**暫定**：保留這個變化，當作成長的驚喜）。

## 6. 九九八十一型

### 6.1 判定

1. 九項中**最高**的是「主」（列），**第二高**的是「副」（欄），交叉的格子就是她的型。
2. 主比第二高多 **25 以上**時，不取副，落在對角線的「**純粹型**」。
3. 同分時依 美→瑟→聲→柔→速→剛→心→智→緣 的順序決定（**暫定**：也可以改為隨機決定，讓各型機率更平均）。

出現率（N，9V 均等隨機的模擬）：純粹型合計約 7.8%（每型約 0.9%），其餘 72 型各約 1%～1.7%。

### 6.2 型名一覽

型名是**個性的稱呼**，不是職業，也不是把兩個字拼接起來的組合詞。每一格的名稱都表現主與副兩者的結合。

| 主＼副 | 美 | 瑟 | 聲 | 柔 | 速 | 剛 | 心 | 智 | 緣 |
|---|---|---|---|---|---|---|---|---|---|
| **美** | **高嶺之花** | 迷人 | 名媛 | 婀娜 | 陽光 | 傲嬌 | 端莊 | 冰山美人 | 寵兒 |
| **瑟** | 尤物 | **媚骨** | 夜鶯 | 舞孃 | 小惡魔 | 火辣 | 御姐 | 風情 | 交際花 |
| **聲** | 仙音 | 撩人 | **歌姬** | 體貼 | 爽朗 | 熱血 | 虔誠 | 辯才 | 健談 |
| **柔** | 優雅 | 慵懶 | 乖巧 | **溫潤** | 靈巧 | 柔韌 | 善良 | 文靜 | 和氣 |
| **速** | 活潑 | 調皮 | 颯爽 | 怪盜 | **飛揚** | 野性 | 衝動 | 精靈 | 外向 |
| **剛** | 凜然 | 豪放 | 大姐頭 | 俐落 | 雷霆 | **猛虎** | 頑強 | 霸氣 | 俠義 |
| **心** | 純潔 | 癡情 | 真誠 | 賢淑 | 元氣 | 剛毅 | **貞德** | 慧心 | 深情 |

粗體為對角線的純粹型。81 個名稱互不重複，開頭的字也互不重複。

## 7. 顯示：櫻瓣花紋

- 九片花瓣，尖端有櫻花的缺口；花瓣長度＝數值（最短也保留約 2 成長度，讓花形不崩壞）；顏色＝三華（魅／身／心），根部濃、尖端淡。
- 中央有花蕊；外側的同心虛線＝等級分界。
- 長的花瓣在後、短的在前疊放。
- 未解鎖的三華：花瓣以含苞的灰色輪廓顯示，不顯示數值。
- 型名顯示在花紋下方（全部解鎖前為「？？」）。
- 角色詳細頁用大的花紋；列表、卡片可以改用等級條或寶石格（依九華能力圖的比較）。
- 將來美術再精緻化（花瓣紋理、光澤、綻放動畫）。

## 8. 重複抽到同一角色

- 同名角色每一隻的 9V 都不同，可以同時擁有。
- 傳承（**暫定**）：消耗一隻同名個體，指定她的一項 9V，取代主角色的對應項目，成功率約 50%；只能指定已經可見的項目。

## 9. 擴張：標籤

新增玩法時，不改動 9V，而是為所有個體**追加標籤**，讓新玩法有自己需要的資料。

- 每個個體保存一個**種子**（招募時產生）。新增一種標籤時，以「種子＋標籤名稱」決定值，所以：
  - 已經招募的舊個體也會自動得到新標籤，不必重抽；
  - 同一個體不論何時讀取，得到的標籤都一樣。
- 標籤可以參考 9V 決定機率（例：速高的個體較容易得到「逃げ」的跑法）。
- 標籤例：

| 玩法 | 標籤類別 | 值的例子 |
|---|---|---|
| VTuber 養成 | 才藝 | 歌、舞、演、畫、廚、琴 |
| 賽跑類 | 跑法 | 逃、先行、插入、追込 |
| 戰鬥類 | 職業 | 前衛、後衛、斥候、術者、補師 |
| 潛入類 | 專長 | 開鎖、扒竊、變裝 |

```js
  skill: { ... },            // 固有技能
  alignment: 30 }            // 德(+) ↔ 惡(−)

// 個體（存檔）
{ uid: "a1b2c3", heroId: "shizuku", seed: 123456789,
  v: { 美: 88, 瑟: 12, 聲: 71, 柔: 40, 速: 33, 剛: 18, 心: 76, 智: 64, 緣: 52 },
  level: 1, exp: 0, affection: 0,
  revealed: ["魅"],          // 已可見的三華
  tags: { talent: "廚" } }   // 新玩法追加的標籤
```
