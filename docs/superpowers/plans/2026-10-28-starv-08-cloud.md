# starV 計畫 8：雲端存檔 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 實作規格 §18：在公司分頁啟用雲端存檔（產生存檔 ID）、換裝置時輸入 ID 或掃描 QR 接回、同時只允許 1 台裝置進行中（另一台轉唯讀並提示「在此裝置繼續」）、以伺服器時間換算離線補算、每 30 秒與重要時點上傳、斷線時暫存恢復後補傳。

**Architecture:** 拆成兩層：`starv_cloud.js`（沒有 DOM：純函式＋依賴注入的控制器 `create({ gs, storage, app, onStatus })`，node 用假的 GameStorage 就能測兩台裝置互動）、`starv_cloud_ui.js`（公司分頁的雲端卡、`?cloud=<ID>` 連結的接回確認、唯讀遮罩、上傳時機）。資料放在 `games/<存檔 ID>/rtState/starv`（沿用既有 `rtState`，不需要修改 `database.rules.json`）。`starv.js` 提供 `App.adopt()`（採用另一份 state 並補算）、`App.setReadOnly()`、`App.onChange()`。

**Tech Stack:** 既有 `PriTestGameStorage`（`rtSet`／`rtSubscribe`／`rtTransaction`／`serverNow`／`serverTimeOffset`／`generateCloudGameId`）、既有 `PriTestQRCode.renderToCanvas`、Vanilla ES5（Promise 可用）、node、Playwright、Firebase Local Emulator（`tools/midnight_check/node_modules/.bin/firebase`）。

## Global Constraints

- 規格 §18：設定中啟用 → `GS.generateCloudGameId()` 產生存檔 ID，寫入 `games/<id>/rtState/starv`（沿用既有 `rtState` 子節點，不需要修改 `database.rules.json`）
- 規格 §18：換裝置：輸入存檔 ID 或掃描 QR（`qrcode.js`）
- 規格 §18：雲端資料 `{ savedAt, deviceId, data }`；以 `rtTransaction` 寫入 `activeDevice`，同時只允許 1 台裝置進行中，另一台開啟時提示「在此裝置繼續」（另一台轉為唯讀）
- 規格 §18：時間使用 `GS.serverNow()`
- 規格 §18：上傳：每 30 秒，或抽卡、頒獎、新紀元等重要時點；斷線時暫存，恢復後補傳
- 規格 §17：接回時覆蓋本機存檔前自動備份（`Store.save` 會把舊存檔搬到 `-backup`）
- 未啟用雲端時不載入 Firebase SDK、不連網路（`game_storage.js` 在 `storageMode !== "cloud"` 前什麼都不做；本計畫只在使用者按下按鈕或已啟用時才呼叫）
- 不修改 `game_storage.js`、`database.rules.json` 與其他遊戲；CLAUDE.md §5.2.1 前綴（`sv_`、`.sv-`、`PriTestStarv*`）；推送前遞增版本號
- 測試頁面按鈕一律用 `dispatchEvent`（CLAUDE.md §4.6）

## 資料格式

`games/<存檔 ID>/rtState/starv/save`：

```js
{ savedAt: 伺服器毫秒, deviceId: "d<16 hex>", version: st.version,
  tickAt: st.lastTickAt 換算成伺服器時間, name: 公司名, day: st.day,
  data: JSON.stringify(st) }   // Firebase 會丟掉空陣列／空物件，所以 state 一律存成字串
```

`games/<存檔 ID>/rtState/starv/activeDevice`：`{ deviceId, since: 伺服器毫秒 }`

本機：`localStorage["pritest-starv-cloud"] = { id, lastSync, pending }`（lastSync＝本機最後一次上傳或採用的 `savedAt`）、`localStorage["pritest-starv-device"] = "d<16 hex>"`。

```js
// 假的 PriTestGameStorage：所有裝置共用同一個記憶體資料庫；寫入與通知都是非同步（跟 Firebase 一樣）；
// setOnline(false) 時 rtSet 的 Promise 不會完成，恢復連線才一起寫入（模擬 Firebase SDK 的離線佇列）
function fakeCloud() {
  var db = {}, subs = [], clock = { t: 1e12 }, online = true, queued = [];
  function key(id, sub) { return id + "/" + sub; }
  function copy(v) { return v == null ? null : JSON.parse(JSON.stringify(v)); }
  function notify(k) { subs.slice().forEach(function (s) { if (s.k === k) s.fn(copy(db[k])); }); }
  var gs = {
    generateCloudGameId: function () { return "g0123456789abcdef0123456789abcdef"; },
    serverNow: function () { return clock.t; },
    serverTimeOffset: function () { return 0; },
    rtSet: function (id, mode, sub, v) {
      var k = key(id, sub);
      function apply() { db[k] = copy(v); notify(k); }
      if (!online) return new Promise(function (res) { queued.push(function () { apply(); res(); }); });
      return Promise.resolve().then(apply);
    },
    rtSubscribe: function (id, mode, sub, fn) {
      var s = { k: key(id, sub), fn: fn };
      subs.push(s);
      Promise.resolve().then(function () { if (subs.indexOf(s) >= 0) fn(copy(db[s.k])); });
      return function () { var i = subs.indexOf(s); if (i >= 0) subs.splice(i, 1); };
    },
    rtTransaction: function (id, mode, sub, fn) {
      var k = key(id, sub);
      return Promise.resolve().then(function () {
        var nv = fn(copy(db[k]));
        if (nv === undefined) return null;
        db[k] = copy(nv); notify(k);
        return copy(nv);
      });
    }
  };
  return {
    gs: gs, db: db, clock: clock,
    setOnline: function (b) { online = b; if (b) queued.splice(0).forEach(function (f) { f(); }); }
  };
}

}

  eq(A4.info().enabled, false);
```

```js
// 明星經紀 starV：雲端存檔（規格 §18）。
// 存在 games/<存檔 ID>/rtState/starv（沿用既有 rtState 子節點，不需要修改 database.rules.json）：
//   save         { savedAt, deviceId, version, tickAt, name, day, data }：data 是整個 state 的 JSON 字串
//                （Firebase 會丟掉空陣列／空物件，所以不直接存物件）；tickAt 是 lastTickAt 換算成伺服器時間
//   activeDevice { deviceId, since }：以 rtTransaction 寫入；同時只有 1 台裝置進行中，其他裝置轉為唯讀
// 時間一律經過 GS.serverNow()：換裝置時用伺服器時間換回本機時間，跨裝置的離線補算才正確。
// 本機：localStorage["pritest-starv-cloud"] = { id, lastSync, pending }、["pritest-starv-device"] = 裝置 ID。
// 這個檔案沒有 DOM：純函式＋控制器（依賴注入 gs／storage／app），node 可以直接測；畫面在 starv_cloud_ui.js。
(function () {
  "use strict";

  var root = typeof window !== "undefined" ? window : globalThis;
  var Store = root.PriTestStarvStore;
  var CFG_KEY = "pritest-starv-cloud";
  var DEVICE_KEY = "pritest-starv-device";
  var SAVE = "starv/save";
  var ACTIVE = "starv/activeDevice";
  var READ_TIMEOUT_MS = 15000;

  function validId(id) { return typeof id === "string" && /^g[0-9a-f]{32}$/.test(id); }

  function envelope(st, deviceId, localNow, serverNow) {
    return {
      savedAt: serverNow, deviceId: deviceId, version: st.version,
      tickAt: st.lastTickAt - localNow + serverNow,
      name: st.company.name || "", day: st.day,
      data: JSON.stringify(st)
    };
  }

  // 雲端封包 → state（經過 Store.parse 驗證與 migrate）；lastTickAt 換回本機時間，不會落在本機的未來
  function unpack(env, localNow, serverNow) {
    if (!env || typeof env.data !== "string") throw new Error("starV: 雲端存檔格式不正確");
    var st = Store.parse(env.data);
    if (typeof env.tickAt === "number" && isFinite(env.tickAt)) st.lastTickAt = Math.min(localNow, env.tickAt - serverNow + localNow);
    return st;
  }

  // rtTransaction 的 updateFn：回傳 undefined＝放棄（別台進行中且不是強制接回）
  function claimUpdate(cur, deviceId, serverNow, force) {
    if (!force && cur && cur.deviceId && cur.deviceId !== deviceId) return undefined;
    return { deviceId: deviceId, since: serverNow };
  }

  // 已啟用雲端的裝置重新開啟時：別台進行中 → 唯讀；雲端有別台傳的、比本機最後同步新的存檔 → 採用；否則上傳本機
  function decide(o) {
    if (o.active && o.active.deviceId && o.active.deviceId !== o.deviceId) return "locked";
    if (o.remote && o.remote.deviceId !== o.deviceId && o.remote.savedAt > (o.lastSync || 0)) return "adopt";
    return "upload";
  }

  // 重要時點（規格 §18：抽卡、頒獎、新紀元）：這個字串改變就立即上傳
  function marks(st) {
    var h = st.awards && st.awards.history[0];
    return [st.stats.pulls, h ? h.year : 0, st.era].join("|");
  }

  function linkFor(href, id) { return String(href).split("#")[0].split("?")[0] + "?cloud=" + id; }
  function idFromSearch(search) {
    var m = /[?&]cloud=([^&#]*)/.exec(search || "");
    return m ? decodeURIComponent(m[1]) : null;
  }
  function stripCloudParam(search) {
    return String(search || "").replace(/([?&])cloud=[^&#]*&?/, "$1").replace(/[?&]$/, "");
  }

  function readJson(storage, key) {
    try { var v = storage.getItem(key); return v ? JSON.parse(v) : null; } catch (e) { return null; }
  }
  function writeJson(storage, key, v) {
    try { if (v === null) storage.removeItem(key); else storage.setItem(key, JSON.stringify(v)); } catch (e) { /* 只是記不住 */ }
  }
  function randomHex(bytes) {
    var s = "", c = root.crypto, i;
    if (c && c.getRandomValues) {
      var b = new Uint8Array(bytes);
      c.getRandomValues(b);
      for (i = 0; i < bytes; i++) s += (b[i] < 16 ? "0" : "") + b[i].toString(16);
      return s;
    }
    for (i = 0; i < bytes * 2; i++) s += Math.floor(Math.random() * 16).toString(16);
    return s;
  }

  // opts：gs（PriTestGameStorage 相容）、storage（localStorage 相容，可為 null）、
  //       app（st／now／adopt／setReadOnly）、onStatus（狀態改變時呼叫）、readTimeoutMs
  function create(opts) {
    var gs = opts.gs, storage = opts.storage, app = opts.app;
    var onStatus = opts.onStatus || function () {};
    var timeoutMs = opts.readTimeoutMs || READ_TIMEOUT_MS;
    var device = null;
    try { device = storage.getItem(DEVICE_KEY); } catch (e) { /* 沒有 storage */ }
    if (!device) {
      device = "d" + randomHex(8);
      try { storage.setItem(DEVICE_KEY, device); } catch (e) { /* 只是記不住 */ }
    }
    var cfg = readJson(storage, CFG_KEY);
    if (cfg && !validId(cfg.id)) cfg = null;
    var locked = false, busy = false, attached = false;
    var active = null, unsub = null, lastMarks = null;

    function info() {
      return { enabled: !!cfg, id: cfg ? cfg.id : null, lastSync: cfg ? cfg.lastSync || 0 : 0, pending: !!(cfg && cfg.pending),
        locked: locked, deviceId: device, busy: busy };
    }
    function status() { onStatus(info()); }
    function saveCfg() { writeJson(storage, CFG_KEY, cfg); }

    // 讀一次：rtSubscribe 收到第一個值就解除；逾時 reject（離線或 Firebase 載入失敗）
    function readOnce(id, sub) {
      return new Promise(function (resolve, reject) {
        var done = false, off = null;
        var timer = setTimeout(function () { if (done) return; done = true; if (off) off(); reject(new Error("starV: 雲端讀取逾時")); }, timeoutMs);
        off = gs.rtSubscribe(id, "cloud", sub, function (v) {
          if (done) return;
          done = true; clearTimeout(timer);
          Promise.resolve().then(function () { if (off) off(); });
          resolve(v);
        });
      });
    }

    function setLocked(b) {
      if (locked === b) return;
      locked = b;
      app.setReadOnly(b);
      status();
    }
    // 持續監看 activeDevice：別台接手就轉唯讀（解除唯讀只走 takeover）
    function watch() {
      if (unsub) unsub();
      unsub = gs.rtSubscribe(cfg.id, "cloud", ACTIVE, function (v) {
        active = v;
        if (v && v.deviceId && v.deviceId !== device) setLocked(true);
      });
    }
    function claim(force) {
      return gs.rtTransaction(cfg.id, "cloud", ACTIVE, function (cur) { return claimUpdate(cur, device, gs.serverNow(), force); })
        .then(function (v) { if (v) active = v; return !!(v && v.deviceId === device); });
    }
    function adopt(env) {
      var st = unpack(env, app.now(), gs.serverNow());
      cfg.lastSync = env.savedAt;
      saveCfg();
      lastMarks = marks(st);
      app.adopt(st);
    }

    // 上傳本機 state。pending 先寫進本機，rtSet 完成才清掉（離線時 Firebase SDK 會暫存，恢復後送出）
    function upload() {
      var st = app.st();
      if (!cfg || locked || !st) return Promise.resolve(false);
      if (active && active.deviceId && active.deviceId !== device) return Promise.resolve(false);
      var id = cfg.id, env = envelope(st, device, app.now(), gs.serverNow());
      cfg.pending = true;
      saveCfg();
      lastMarks = marks(st);
      status();
      return gs.rtSet(id, "cloud", SAVE, env).then(function () {
        if (!cfg || cfg.id !== id) return false;
        cfg.pending = false;
        cfg.lastSync = env.savedAt;
        saveCfg();
        status();
        return true;
      });
    }

    function attach() {
      if (!cfg) { status(); return Promise.resolve("off"); }
      var id = cfg.id;
      return Promise.all([readOnce(id, ACTIVE), readOnce(id, SAVE)]).then(function (r) {
        if (!cfg || cfg.id !== id) return "off";
        attached = true;
        active = r[0];
        var d = decide({ active: r[0], remote: r[1], deviceId: device, lastSync: cfg.lastSync });
        watch();
        if (d === "locked") { setLocked(true); return d; }
        return claim(false).then(function (ok) {
          if (!ok) return "conflict";   // 別台剛好搶先：watch() 會收到並轉唯讀
          if (d === "adopt") {
            try { adopt(r[1]); } catch (e) { d = "upload"; }   // 雲端存檔壞掉：保留本機並覆蓋上去
          }
          return upload().then(function () { return d; });
        });
      }, function () { status(); return "offline"; });
    }

    function enable() {
      if (cfg) return Promise.resolve(cfg.id);
      var id = gs.generateCloudGameId();
      cfg = { id: id, lastSync: 0, pending: false };
      busy = true;
      status();
      return claim(true).then(function (ok) {
        busy = false;
        if (!ok) { cfg = null; status(); return null; }
        saveCfg();
        attached = true;
        watch();
        return upload().then(function () { return id; });
      });
    }

    function disable() {
      if (unsub) unsub();
      unsub = null; cfg = null; active = null; attached = false;
      saveCfg();
      setLocked(false);
      status();
    }

    function preview(id) {
      if (!validId(id)) return Promise.resolve(null);
      return readOnce(id, SAVE).then(function (env) { return env && typeof env.data === "string" ? env : null; });
    }

    // 換裝置接回：先驗證封包，再強制成為進行中裝置並採用雲端 state
    function connect(id, env) {
      try { unpack(env, app.now(), gs.serverNow()); } catch (e) { return Promise.reject(e); }
      if (unsub) unsub();
      unsub = null;
      cfg = { id: id, lastSync: 0, pending: false };
      return claim(true).then(function (ok) {
        if (!ok) { cfg = null; status(); return false; }
        saveCfg();
        attached = true;
        adopt(env);
        setLocked(false);
        watch();
        status();
        return true;
      });
    }

    // 唯讀中按「在此裝置繼續」：強制接手，雲端有別台傳的較新存檔就採用
    function takeover() {
      if (!cfg) return Promise.resolve(false);
      busy = true;
      status();
      return claim(true).then(function (ok) {
        if (!ok) { busy = false; status(); return false; }
        return readOnce(cfg.id, SAVE).then(function (env) {
          if (env && env.deviceId !== device && env.savedAt > (cfg.lastSync || 0)) adopt(env);
          busy = false;
          setLocked(false);
          status();
          return upload().then(function () { return true; });
        });
      }).catch(function () { busy = false; status(); return false; });
    }

    // 每 30 秒：還沒接上（啟動時離線）就再接一次，否則上傳
    function tick() {
      if (!cfg) return Promise.resolve(false);
      return attached ? upload() : attach();
    }
    function changed() {
      if (!cfg || locked) return;
      var st = app.st();
      if (!st) return;
      var m = marks(st);
      if (lastMarks !== null && m !== lastMarks) upload();
      else lastMarks = m;
    }
    function onOnline() { if (cfg && (cfg.pending || !attached)) tick(); }

    return {
      info: info, deviceId: function () { return device; },
      attach: attach, enable: enable, disable: disable, preview: preview, connect: connect, takeover: takeover,
      upload: upload, tick: tick, changed: changed, onOnline: onOnline
    };
  }

  root.PriTestStarvCloud = {
    CFG_KEY: CFG_KEY, DEVICE_KEY: DEVICE_KEY, SAVE: SAVE, ACTIVE: ACTIVE,
    validId: validId, envelope: envelope, unpack: unpack, claimUpdate: claimUpdate, decide: decide, marks: marks,
    linkFor: linkFor, idFromSearch: idFromSearch, stripCloudParam: stripCloudParam, create: create
  };
})();
```

```js
        }, "sv-btn-primary sv-btn-big", { "data-act": "cloud-takeover" })
      ])
    ]);
    (document.querySelector(".sv-root") || document.body).appendChild(lockEl);
  }

  function onStatus(info) {
    renderLock(info);
    if (app && app.st()) app.render();
  }

  function askConnect(id) {
    if (!Cloud.validId(id)) { UI.toast(t("sv_cloud_err_id"), "bad"); return; }
    ctl.preview(id).then(function (env) {
      if (!env) { UI.toast(t("sv_cloud_err_notfound"), "bad"); return; }
      UI.openModal(function (box, close) {
        box.appendChild(UI.modalHead(t("sv_cloud_confirm_title"), close));
        box.appendChild(el("p", { text: t("sv_cloud_confirm_body", { name: env.name || t("sv_company_default"), date: UI.dateText(env.day), saved: savedText(env.savedAt) }) }));
        box.appendChild(el("p", { class: "sv-small sv-muted", text: t("sv_cloud_confirm_note") }));
        box.appendChild(el("div", { class: "sv-row sv-row-end" }, [
          UI.btn(t("sv_cancel"), close, "sv-btn-ghost", { "data-act": "cloud-connect-cancel" }),
          UI.btn(t("sv_cloud_confirm_go"), function () {
            close();
            ctl.connect(id, env).then(function (ok) {
              ui.idText = "";
              UI.toast(ok ? t("sv_cloud_connected") : t("sv_cloud_err_net"), ok ? "gold" : "bad");
            }, function () { UI.toast(t("sv_err_import"), "bad"); });
          }, "sv-btn-danger", { "data-act": "cloud-connect-confirm" })
        ]));
      });
    }, function () { UI.toast(t("sv_cloud_err_net"), "bad"); });
  }

  function card(App) {
    if (!ctl) return null;
    var info = ctl.info();
    var rows = [el("h3", { text: t("sv_cloud") }), el("p", { class: "sv-small sv-muted", text: t("sv_cloud_hint") })];
    if (!info.enabled) {
      rows.push(el("div", { class: "sv-row" }, [UI.btn(t("sv_cloud_enable"), function () {
        ctl.enable().then(function (id) {
          UI.toast(id ? t("sv_cloud_enabled") : t("sv_cloud_err_net"), id ? "gold" : "bad");
          App.render();
        });
      }, "sv-btn-primary", { "data-act": "cloud-enable" })]));
      var input = el("input", { class: "sv-input", placeholder: t("sv_cloud_id_ph"), value: ui.idText, "data-act": "cloud-id-input",
        oninput: function () { ui.idText = input.value.trim(); } });
      rows.push(el("label", { class: "sv-field" }, [el("span", { text: t("sv_cloud_id_label") }), input]));
      rows.push(el("div", { class: "sv-row" }, [UI.btn(t("sv_cloud_connect"), function () { askConnect(ui.idText); }, "", { "data-act": "cloud-connect" })]));
    } else {
      var link = Cloud.linkFor(location.href, info.id);
      var canvas = el("canvas", { class: "sv-cloud-qr", "data-act": "cloud-qr" });
      try { window.PriTestQRCode.renderToCanvas(canvas, link, { level: "L", scale: 4, margin: 2 }); } catch (e) { /* 沒有 QR 也能輸入 ID */ }
      rows.push(el("label", { class: "sv-field" }, [el("span", { text: t("sv_cloud_id_label") }),
        el("input", { class: "sv-input sv-cloud-id", readonly: true, value: info.id, "data-act": "cloud-id" })]));
      rows.push(el("div", { class: "sv-row" }, [
        UI.btn(t("sv_save_copy"), function () { copy(info.id); }, "sv-btn-ghost", { "data-act": "cloud-copy" }),
        UI.btn(t("sv_cloud_copy_link"), function () { copy(link); }, "sv-btn-ghost", { "data-act": "cloud-copy-link" })
      ]));
      rows.push(canvas);
      rows.push(el("p", { class: "sv-small sv-muted", text: t("sv_cloud_qr_hint") }));
      rows.push(el("p", { class: "sv-small sv-cloud-warn", text: t("sv_cloud_warn") }));
      rows.push(el("div", { class: "sv-small", "data-act": "cloud-status", text: statusText(info) }));
      rows.push(el("div", { class: "sv-row sv-row-end" }, [
        UI.btn(t("sv_cloud_upload"), function () { ctl.upload().then(function (ok) { if (ok) UI.toast(t("sv_cloud_uploaded")); }); }, "", { "data-act": "cloud-upload" }),
        UI.btn(t("sv_cloud_disable"), function () { ctl.disable(); App.render(); }, "sv-btn-ghost", { "data-act": "cloud-disable" })
      ]));
    }
    return el("div", { class: "sv-card sv-cloud" }, rows);
  }

  function boot(App) {
    app = App;
    ctl = Cloud.create({ gs: GS, storage: safeStorage(), app: App, onStatus: onStatus });
    App.onChange(function () { ctl.changed(); });
    ctl.attach();
    setInterval(function () { if (document.visibilityState !== "hidden") ctl.tick(); }, UPLOAD_EVERY_MS);
    document.addEventListener("visibilitychange", function () { if (document.visibilityState === "hidden") ctl.upload(); });
    window.addEventListener("online", function () { ctl.onOnline(); });
    window.addEventListener("i18n:change", function () { if (lockEl) { removeLock(); renderLock(ctl.info()); } });
    // QR／連結：?cloud=<ID> → 先從網址拿掉（重新整理不會再問），再詢問是否接回
    var id = Cloud.idFromSearch(location.search);
    if (id !== null) {
      try { history.replaceState(null, "", location.pathname + Cloud.stripCloudParam(location.search) + location.hash); } catch (e) { /* 舊瀏覽器 */ }
      askConnect(id);
    }
  }

  window.PriTestStarvCloudUI = { boot: boot, card: card, ctl: function () { return ctl; } };
})();
```

### Task 3：Firebase emulator 上的兩台裝置 E2E

**Files:**

**Interfaces:**
- Consumes：Task 2 的 DOM（`data-act` 名稱見 Task 2 Interfaces）、`window.PriTestStarvCloudUI.ctl().info()`、`window.PriTestStarv.state()`／`.app.readOnly()`；`game_storage.js` 的 emulator 旗標（`sessionStorage.pritestRtdbEmulator = "1"`，`pritestRtdbEmulatorPort`）
- Produces：`node tools/starv_check/cloud_check.js`（全部通過時 exit 0）

- [ ] **Step 1：建立 `tools/starv_check/cloud_check.js`**

```js
// ============================================================================
// 明星經紀 starV 雲端存檔的兩台裝置檢查（Firebase Local Emulator，不連真的 Firebase 專案、不經過 App Check）：
//   A 開業 → 啟用雲端（ID、QR）→ B 用 ?cloud=<ID> 連結接回 → A 轉唯讀 → A 在此裝置繼續 → B 轉唯讀
//   → A 抽卡（重要時點立即上傳）→ B 接回後看得到抽卡結果 → A 重新整理後仍是唯讀
// 前置：
//   1. py -3 generate.py
//   2. py -3 -m http.server 8946 --directory dist
//   3. tools/midnight_check/node_modules/.bin/firebase emulators:start --only database,auth --project demo-starv
//      （9000 被占用時改 firebase.json 以外的 port 啟動，並設定環境變數 STARV_RTDB_PORT）
// 執行：node tools/starv_check/cloud_check.js
// 兩個 browser context＝兩台裝置（localStorage 各自獨立）。按鈕一律用 dispatchEvent（CLAUDE.md §4.6）。
// ============================================================================
"use strict";
var path = require("path");
var assert = require("assert");
var chromium = require(require.resolve("playwright", { paths: [path.join(__dirname, "..", "midnight_check")] })).chromium;

var PAGE = process.env.STARV_PAGE || "http://localhost:8946/starv/index.html";
var RTDB_PORT = process.env.STARV_RTDB_PORT || "9000";

async function device(browser) {
  var ctx = await browser.newContext({ viewport: { width: 420, height: 900 } });
  await ctx.addInitScript(function (port) {
    try { sessionStorage.setItem("pritestRtdbEmulator", "1"); sessionStorage.setItem("pritestRtdbEmulatorPort", port); } catch (e) { /* 忽略 */ }
  }, RTDB_PORT);
  var page = await ctx.newPage();
  page.errors = [];
  page.on("pageerror", function (e) { page.errors.push(e.message); });
  return page;
}
async function act(page, name) {
  await page.waitForSelector('[data-act="' + name + '"]', { state: "attached", timeout: 15000 });
  await page.dispatchEvent('[data-act="' + name + '"]', "click");
}
async function tab(page, id) {
  await page.dispatchEvent('.sv-tab[data-tab="' + id + '"]', "click");
  await page.waitForSelector('.sv-tab.sv-on[data-tab="' + id + '"]');
}
function info(page) { return page.evaluate(function () { return window.PriTestStarvCloudUI.ctl().info(); }); }
function st(page) { return page.evaluate(function () { return JSON.parse(JSON.stringify(window.PriTestStarv.state())); }); }
async function quiet(page) {
  await page.evaluate(function () { if (window.PriTestStarvData) window.PriTestStarvData.BAL.eventDailyChance = 0; });
}

var steps = [];
function step(name, fn) { steps.push([name, fn]); }
var ctx = {};

step("A：開業 → 啟用雲端 → 顯示 ID 與 QR", async function () {
  var A = ctx.A;
  await A.goto(PAGE + "?debug=1");
  await A.waitForSelector(".sv-welcome input");
  await quiet(A);
  await A.fill(".sv-welcome input", "雲端甲社");
  await act(A, "start");
  await A.waitForSelector(".sv-top");
  await tab(A, "company");
  await act(A, "cloud-enable");
  await A.waitForSelector('[data-act="cloud-id"]', { timeout: 20000 });
  ctx.id = await A.$eval('[data-act="cloud-id"]', function (x) { return x.value; });
  assert.ok(/^g[0-9a-f]{32}$/.test(ctx.id), "存檔 ID：" + ctx.id);
  var qrW = await A.$eval('[data-act="cloud-qr"]', function (c) { return c.width; });
  assert.ok(qrW > 50, "QR 已繪製");
  await A.waitForFunction(function () { var i = window.PriTestStarvCloudUI.ctl().info(); return i.lastSync > 0 && !i.pending; }, null, { timeout: 15000 });
});

step("B：用連結接回 → 公司名一致；A 轉唯讀", async function () {
  var A = ctx.A, B = ctx.B;
  await B.goto(PAGE + "?debug=1&cloud=" + ctx.id);
  await act(B, "cloud-connect-confirm");
  await B.waitForSelector(".sv-top", { timeout: 15000 });
  await quiet(B);
  assert.strictEqual((await st(B)).company.name, "雲端甲社");
  assert.ok(!/cloud=/.test(await B.evaluate(function () { return location.search; })), "網址拿掉 cloud 參數");
  await A.waitForSelector(".sv-cloud-lock", { timeout: 15000 });
  assert.strictEqual(await A.evaluate(function () { return window.PriTestStarv.app.readOnly(); }), true, "A 唯讀");
  var money = (await st(A)).company.money;
  await A.evaluate(function () { window.PriTestStarv.app.act(function (s) { s.company.money += 99999; }); });
  assert.strictEqual((await st(A)).company.money, money, "唯讀時操作無效");
});

step("A：在此裝置繼續 → A 解除唯讀、B 轉唯讀", async function () {
  var A = ctx.A, B = ctx.B;
  await act(A, "cloud-takeover");
  await A.waitForSelector(".sv-cloud-lock", { state: "detached", timeout: 15000 });
  await B.waitForSelector(".sv-cloud-lock", { timeout: 15000 });
  assert.strictEqual(await A.evaluate(function () { return window.PriTestStarv.app.readOnly(); }), false);
});

step("A：抽卡（重要時點立即上傳）→ B 接回後看得到", async function () {
  var A = ctx.A, B = ctx.B;
  await tab(A, "gacha");
  await act(A, "pull-ticket-10");
  await A.waitForSelector(".sv-reveal");
  await act(A, "reveal-skip");
  await act(A, "reveal-done");
  for (var i = 0; i < 10 && await A.$('[data-act="spot-done"]'); i++) await act(A, "spot-done");
  var pulls = (await st(A)).stats.pulls;
  assert.ok(pulls >= 10, "A 抽了 " + pulls);
  await A.waitForFunction(function () { return !window.PriTestStarvCloudUI.ctl().info().pending; }, null, { timeout: 15000 });
  await act(B, "cloud-takeover");
  await B.waitForSelector(".sv-cloud-lock", { state: "detached", timeout: 15000 });
  assert.strictEqual((await st(B)).stats.pulls, pulls, "B 採用 A 的抽卡結果");
  await A.waitForSelector(".sv-cloud-lock", { timeout: 15000 });
});

step("A：重新整理 → 仍是唯讀（B 進行中）；狀態顯示唯讀", async function () {
  var A = ctx.A;
  await A.reload();
  await A.waitForSelector(".sv-cloud-lock", { timeout: 20000 });
  await tab(A, "company");
  var text = await A.$eval('[data-act="cloud-status"]', function (x) { return x.textContent; });
  assert.ok(text.length > 0 && !/sv_/.test(text), "狀態：" + text);
  assert.strictEqual((await info(A)).locked, true);
});

(async function main() {
  var browser = await chromium.launch();
  ctx.A = await device(browser);
  ctx.B = await device(browser);
  var fails = 0;
  for (var i = 0; i < steps.length; i++) {
    try { await steps[i][1](); console.log("ok   " + steps[i][0]); }
    catch (e) { fails++; console.log("FAIL " + steps[i][0] + "：" + e.message); break; }
  }
  var errors = ctx.A.errors.concat(ctx.B.errors);
  if (errors.length) { fails++; console.log("FAIL 頁面錯誤：" + errors.join(" | ")); }
  await browser.close();
  console.log(fails ? "有失敗" : "全部 " + steps.length + " 個步驟通過");
  process.exit(fails ? 1 : 0);
})();
```
