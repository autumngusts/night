# 武俠合成（gousei）簡易版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增小遊戲「武俠合成」：從初始物體兩兩合成，先親手合出自己 3 張任務物的玩家獲勝；武俠／和風兩主題各 5,000 種以上物體。

**Architecture:** 依照 utau 的既有模式：`gousei_core.js` 是純函式規則引擎（node 可測），`gousei.js` 負責 UI 與 `localStorage`。主題資料由 `tools/gousei_data/build.py` 從分類 JSON 驗證、計算階段後輸出 `static_src/gousei_data_<theme>.js`，頁面選主題時才動態載入。

**Tech Stack:** Vanilla ES5（IIFE + `window.PriTest*`）、Python 3（建置）、node（core 檢查）、Playwright（UI 檢查，借用 `tools/midnight_check` 的 node_modules）。

設計書：`docs/superpowers/specs/2026-10-16-gousei-design.md`

## Global Constraints

* 回覆、文件、commit message 一律繁體中文；識別字維持原文。
* 主題：`wuxia` 初始物體 金、木、水、火、土；`wafu` 初始物體 火、水、雷、風、土。
* 每個主題物體數（不含初始與廢料）≥ 5,000。
* 任務：每人 中階 ×1（階段 3〜4）＋ 高階 ×2（階段 5〜7），全體不重複，不含廢料與初始物體。
* 提示只顯示名稱、分類、階段。
* 組合必有結果：無配方 → 依 key 雜湊選廢料；任一材料是廢料 → 必為廢料。
* 只有在自己回合親手合出自己的任務物才算達成；最先 3/3 立即獲勝。
* 人數 2〜8；模式 `shared`（同一裝置）／`split`（分別裝置，不同步）。
* 每輪每人合成一次；可復原一層。
* 修改 `site_src/` 或 `static_src/` 後要跑 `py -3 generate.py`。
* Playwright 腳本以 `dispatchEvent` 或一般 click 皆可（本遊戲無每幀重繪）。
* 不 push（push 前要遞增 `site_src/version.py`，由使用者決定時機）。

### Task 1: 規則引擎 `gousei_core.js`

**Files:**
- Create: `static_src/gousei_core.js`
- Test: `tools/gousei_check/core_check.js`

**Interfaces:**
- Consumes: 主題資料物件 `data`（格式見 Task 2 輸出）：
  `{ id, name:{zh,ja}, basics:[id], junk:[id], categories:[{id,zh,ja}], items:[[id,zh,ja,cat,tier]], recipes:{"a|b": id} }`
- Produces（`window.PriTestGouseiCore`）：
  * `MID_TIERS = [3,4]`、`HIGH_TIERS = [5,7]`
  * `hashStr(s) -> uint32`、`makeRng(seed) -> () => [0,1)`、`newSeed(rand) -> string`（8 碼 base36）
  * `pairKey(a,b) -> "a|b"`（排序後）
  * `indexTheme(data) -> theme`：`{ id, data, items:[{id,zh,ja,cat,tier}], byId, basics, junk, junkSet, recipes, catById }`
  * `combine(theme,a,b) -> id`
  * `dealTargets(theme, seed, playerCount) -> [[mid,high,high], ...]`（不足時 throw `Error("not-enough-targets")`）
  * `newGame(theme, {seed, mode, names}) -> state`
  * `currentPlayer(state) -> player`
  * `applyCombine(theme, state, a, b) -> {state, entry}`（throw `Error("game-over")`／`Error("not-in-pool")`）
  * `undo(state) -> state|null`
  * `joinParam(state, index) -> "theme.seed.count.index"`、`parseJoin(str) -> {themeId,seed,count,index}|null`
  * state 形狀：`{version:1, themeId, seed, mode, players:[{id,name,targets:[3],done:[]}], pool:[id], round, turn, log:[entry], winner:null|playerId, prev:state|null}`
  * entry 形狀：`{round, playerId, a, b, result, isNew, achieved}`

```js
var assert = require("assert");

var SRC = path.join(__dirname, "..", "..", "static_src");
var win = {};
new Function("window", fs.readFileSync(path.join(SRC, "gousei_core.js"), "utf8"))(win);

// ---- 測試用小主題：每層 3 個物體，階段 1〜7 ----
function fixture() {
  var items = [["b1", "甲", "甲", "basic", 0], ["b2", "乙", "乙", "basic", 0],
    ["z1", "灰", "灰", "junk", 0], ["z2", "渣", "渣", "junk", 0]];
  var recipes = {};
  var levels = ["i", "j", "k", "l", "m", "n", "o"];
  var prev = null;
  levels.forEach(function (L, idx) {
    var tier = idx + 1;
    var ids = [L + "1", L + "2", L + "3"];
    ids.forEach(function (id) { items.push([id, id, id, "c", tier]); });
    if (!prev) {
      recipes["b1|b1"] = ids[0]; recipes["b1|b2"] = ids[1]; recipes["b2|b2"] = ids[2];
    } else {
      recipes[Core.pairKey(prev[0], prev[1])] = ids[0];
      recipes[Core.pairKey(prev[1], prev[2])] = ids[1];
      recipes[Core.pairKey(prev[0], prev[2])] = ids[2];
    }
    prev = ids;
  });
  return { id: "fx", name: { zh: "測試", ja: "テスト" }, basics: ["b1", "b2"], junk: ["z1", "z2"],
    categories: [{ id: "c", zh: "類", ja: "類" }], items: items, recipes: recipes };
}
var theme = Core.indexTheme(fixture());

// ---- 基本工具 ----
assert.strictEqual(Core.pairKey("b", "a"), "a|b");
assert.strictEqual(Core.pairKey("a", "a"), "a|a");
assert.strictEqual(Core.hashStr("abc"), Core.hashStr("abc"));
var r1 = Core.makeRng("s1"), r2 = Core.makeRng("s1");
for (var i = 0; i < 5; i++) assert.strictEqual(r1(), r2());

assert.strictEqual(theme.byId.k1.tier, 3);

// ---- 合成 ----
assert.strictEqual(Core.combine(theme, "b1", "b2"), "i2");
assert.strictEqual(Core.combine(theme, "b2", "b1"), "i2", "順序不影響");
var junk = Core.combine(theme, "b1", "o3");
assert.ok(theme.junkSet[junk], "無配方 → 廢料");
assert.strictEqual(Core.combine(theme, "o3", "b1"), junk, "廢料是確定性的");
assert.ok(theme.junkSet[Core.combine(theme, "z1", "z1")], "廢料 + 廢料 → 廢料");
// 即使把廢料塞進配方表，含廢料的組合仍是廢料
theme.recipes["b1|z1"] = "i1";
assert.ok(theme.junkSet[Core.combine(theme, "b1", "z1")], "材料含廢料 → 廢料");
delete theme.recipes["b1|z1"];

// ---- 發任務 ----
var deal = Core.dealTargets(theme, "seedA", 2);
assert.strictEqual(deal.length, 2);
var seen = {};
deal.forEach(function (ts) {
  assert.strictEqual(ts.length, 3);
  var t0 = theme.byId[ts[0]].tier;
  assert.ok(t0 >= 3 && t0 <= 4, "中階 " + ts[0]);
  [ts[1], ts[2]].forEach(function (id) { var tt = theme.byId[id].tier; assert.ok(tt >= 5 && tt <= 7, "高階 " + id); });
  ts.forEach(function (id) { assert.ok(!seen[id], "任務不重複 " + id); seen[id] = true; });
});
assert.deepStrictEqual(Core.dealTargets(theme, "seedA", 2), deal, "同 seed 相同");
assert.throws(function () { Core.dealTargets(theme, "seedA", 7); }, /not-enough-targets/);

// ---- 開局 ----
var st = Core.newGame(theme, { seed: "seedA", mode: "shared", names: ["A", "B"] });
assert.strictEqual(st.version, 1);
assert.deepStrictEqual(st.pool, ["b1", "b2"]);
assert.deepStrictEqual(st.players[0].targets, deal[0]);
assert.strictEqual(st.players[1].id, "p2");
assert.strictEqual(Core.currentPlayer(st).id, "p1");

// ---- 合成流程：新發現、輪替、輪數 ----
var res = Core.applyCombine(theme, st, "b1", "b2");
assert.strictEqual(res.entry.result, "i2");
assert.strictEqual(res.entry.isNew, true);
assert.strictEqual(res.entry.playerId, "p1");
assert.ok(res.state.pool.indexOf("i2") >= 0);
assert.strictEqual(Core.currentPlayer(res.state).id, "p2");
assert.strictEqual(st.pool.length, 2, "不改動傳入的 state");
var res2 = Core.applyCombine(theme, res.state, "b2", "b1");
assert.strictEqual(res2.entry.isNew, false);
assert.strictEqual(res2.state.round, 2);
assert.strictEqual(res2.state.turn, 0);
assert.throws(function () { Core.applyCombine(theme, res2.state, "b1", "k1"); }, /not-in-pool/);

// ---- 復原：只保留一層 ----
var back = Core.undo(res2.state);
assert.deepStrictEqual(back.pool, res.state.pool);
assert.strictEqual(back.turn, 1);
assert.strictEqual(Core.undo(back), null, "只能復原一層");

// ---- 達成：只算自己回合親手合出 ----
var s3 = Core.newGame(theme, { seed: "x", mode: "shared", names: ["A", "B"] });
s3.players[0].targets = ["k1", "m1", "n1"];
s3.players[1].targets = ["k2", "m2", "n2"];
s3.pool = s3.pool.concat(["j1", "j2", "j3"]);
var a1 = Core.applyCombine(theme, s3, "j2", "j3"); // p1 合出 k2（p2 的任務）
assert.strictEqual(a1.entry.achieved, false, "別人的任務不算");
var a2 = Core.applyCombine(theme, a1.state, "j2", "j3"); // p2 再合出 k2，但已在池子中
assert.strictEqual(a2.entry.achieved, true, "自己親手合出才算（已在池子中也可以）");

assert.strictEqual(a3.entry.achieved, true);

// ---- 勝利 ----
var s4 = Core.newGame(theme, { seed: "x", mode: "shared", names: ["A", "B"] });
s4.players[0].targets = ["k1", "m1", "n1"];
s4.players[0].done = ["m1", "n1"];

assert.strictEqual(w.state.winner, "p1");
assert.strictEqual(w.state.turn, 0, "獲勝後不再輪替");

assert.strictEqual(jp, "fx.seedA.2.1");

assert.strictEqual(Core.parseJoin("garbage"), null);
assert.strictEqual(Core.parseJoin("fx.seedA.9.0"), null, "人數超過 8");
```

```js
// 武俠合成（gousei）規則引擎：純函式，不碰 DOM／localStorage，方便用 node 測試。
//
// 規則（使用者指定，詳見 docs/gousei_game_design.md）：
//   ・組合必有結果：配方表沒有的組合 → 依 key 雜湊選一個廢料；任一材料是廢料 → 必為廢料
//   ・每人任務：中階 ×1（階段 3〜4）＋ 高階 ×2（階段 5〜7），全體不重複
//   ・共用池子，每輪每人合成一次；只有在自己回合親手合出自己的任務物才算達成
//   ・最先達成全部任務者立即獲勝；可復原一層
(function () {
  "use strict";

  var MID_TIERS = [3, 4];
  var HIGH_TIERS = [5, 7];
  var MIN_PLAYERS = 2;
  var MAX_PLAYERS = 8;

  function clone(obj) { return JSON.parse(JSON.stringify(obj)); }

  // FNV-1a 32bit
  function hashStr(s) {
    var h = 0x811c9dc5;
    for (var i = 0; i < s.length; i++) {
      h ^= s.charCodeAt(i);
      h = Math.imul(h, 0x01000193) >>> 0;
    }
    return h >>> 0;
  }

  // mulberry32：同一個 seed 在每台裝置都得到相同序列（分別裝置模式靠這個算出同樣的任務）
  function makeRng(seed) {
    var a = hashStr(String(seed));
    return function () {
      a = (a + 0x6d2b79f5) >>> 0;
      var t = a;
      t = Math.imul(t ^ (t >>> 15), t | 1);
      t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
  }

  function newSeed(rand) {
    var chars = "0123456789abcdefghijklmnopqrstuvwxyz";
    var out = "";
    for (var i = 0; i < 8; i++) out += chars.charAt(Math.floor(rand() * chars.length));
    return out;
  }

  function shuffle(arr, rng) {
    var a = arr.slice();
    for (var i = a.length - 1; i > 0; i--) {
      var j = Math.floor(rng() * (i + 1));
      var tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
    return a;
  }

  function pairKey(a, b) { return a <= b ? a + "|" + b : b + "|" + a; }

  function indexTheme(data) {
    var byId = {};
    var items = data.items.map(function (row) {
      var it = { id: row[0], zh: row[1], ja: row[2], cat: row[3], tier: row[4] };
      byId[it.id] = it;
      return it;
    });
    var junkSet = {};
    data.junk.forEach(function (id) { junkSet[id] = true; });
    var catById = {};
    data.categories.forEach(function (c) { catById[c.id] = c; });
    return { id: data.id, data: data, items: items, byId: byId, basics: data.basics.slice(),
      junk: data.junk.slice(), junkSet: junkSet, recipes: data.recipes, catById: catById };
  }

  function combine(theme, a, b) {
    var key = pairKey(a, b);
    var junkPick = theme.junk[hashStr(key) % theme.junk.length];
    if (theme.junkSet[a] || theme.junkSet[b]) return junkPick;
    return theme.recipes[key] || junkPick;
  }

  function inRange(tier, range) { return tier >= range[0] && tier <= range[1]; }

  function dealTargets(theme, seed, playerCount) {
    var rng = makeRng("targets:" + seed);
    function candidates(range) {
      return theme.items.filter(function (it) {
        return it.cat !== "basic" && !theme.junkSet[it.id] && inRange(it.tier, range);
      }).map(function (it) { return it.id; });
    }
    var mids = shuffle(candidates(MID_TIERS), rng);
    var highs = shuffle(candidates(HIGH_TIERS), rng);
    if (mids.length < playerCount || highs.length < playerCount * 2) throw new Error("not-enough-targets");
    var out = [];
    for (var i = 0; i < playerCount; i++) out.push([mids[i], highs[i * 2], highs[i * 2 + 1]]);
    return out;
  }

  function newGame(theme, opts) {
    var targets = dealTargets(theme, opts.seed, opts.names.length);
    return {
      version: 1,
      themeId: theme.id,
      seed: opts.seed,
      mode: opts.mode,
      players: opts.names.map(function (name, i) {
        return { id: "p" + (i + 1), name: name, targets: targets[i], done: [] };
      }),
      pool: theme.basics.slice(),
      round: 1,
      turn: 0,
      log: [],
      winner: null,
      prev: null
    };
  }

  function currentPlayer(state) { return state.players[state.turn]; }

  function applyCombine(theme, state, a, b) {
    if (state.winner) throw new Error("game-over");
    if (state.pool.indexOf(a) < 0 || state.pool.indexOf(b) < 0) throw new Error("not-in-pool");
    var snap = clone(state);
    snap.prev = null; // 只保留一層復原
    var next = clone(snap);
    next.prev = snap;
    var result = combine(theme, a, b);
    var isNew = next.pool.indexOf(result) < 0;
    if (isNew) next.pool.push(result);
    var p = next.players[next.turn];
    var achieved = p.targets.indexOf(result) >= 0 && p.done.indexOf(result) < 0;
    if (achieved) p.done.push(result);
    var entry = { round: next.round, playerId: p.id, a: a, b: b, result: result, isNew: isNew, achieved: achieved };
    next.log.push(entry);
    if (p.done.length >= p.targets.length) {
      next.winner = p.id;
    } else {
      next.turn += 1;
      if (next.turn >= next.players.length) { next.turn = 0; next.round += 1; }
    }
    return { state: next, entry: entry };
  }

  function undo(state) { return state && state.prev ? state.prev : null; }

  // 分別裝置模式：手機只需要主題、seed、人數、自己的編號，就能算出自己的任務（不同步）
  function joinParam(state, index) {
    return [state.themeId, state.seed, state.players.length, index].join(".");
  }

  function parseJoin(str) {
    var parts = String(str || "").split(".");
    if (parts.length !== 4) return null;
    var count = parseInt(parts[2], 10);
    var index = parseInt(parts[3], 10);
    if (!/^[a-z0-9_]+$/.test(parts[0]) || !/^[0-9a-zA-Z]+$/.test(parts[1])) return null;
    if (!(count >= MIN_PLAYERS && count <= MAX_PLAYERS) || !(index >= 0 && index < count)) return null;
    return { themeId: parts[0], seed: parts[1], count: count, index: index };
  }

  window.PriTestGouseiCore = {
    MID_TIERS: MID_TIERS,
    HIGH_TIERS: HIGH_TIERS,
    MIN_PLAYERS: MIN_PLAYERS,
    MAX_PLAYERS: MAX_PLAYERS,
    hashStr: hashStr,
    makeRng: makeRng,
    newSeed: newSeed,
    pairKey: pairKey,
    indexTheme: indexTheme,
    combine: combine,
    dealTargets: dealTargets,
    newGame: newGame,
    currentPlayer: currentPlayer,
    applyCombine: applyCombine,
    undo: undo,
    joinParam: joinParam,
    parseJoin: parseJoin
  };
})();
```

  * `tools/gousei_data/<theme>/<category>.json`：`{"category": "<category>", "items": [{"id","zh","ja"}], "recipes": [...]}`（物體分類自動為該 category）
- 驗證規則：
  1. id 符合 `^[a-z0-9_]+$`，主題內唯一；zh、ja 名稱主題內各自唯一。
  2. 配方三元素都存在；結果不可為初始或廢料；材料不可為廢料。
  3. 分類檔的配方：結果必須屬於本分類；至少一個材料屬於本分類；材料只能來自本檔、`core.json` 或初始物體。
  4. 同一個 `pairKey` 只能出現一次。
  5. 所有非廢料物體必須能從初始物體合出。
  6. 非 `--skeleton` 時：物體數 ≥ `min_items`、階段 3〜4 ≥ `min_mid`（預設 200）、階段 5〜7 ≥ `min_high`（預設 400）。
- Produces：
  * `load_theme(theme_dir: Path, skeleton: bool = False) -> dict`，回傳 `{"meta", "items": [dict(id,zh,ja,cat,tier,src)], "recipes": {key: id}, "errors": [str], "stats": {...}}`
  * `compute_tiers(basics: list[str], recipes: dict[str,str]) -> dict[str,int]`
  * `render_js(theme: dict) -> str`（輸出 Task 1 的資料物件格式，掛在 `window.PriTestGouseiData[id]`）
  * CLI：`py -3 tools/gousei_data/build.py [theme ...] [--check] [--skeleton]`

```python
"""武俠合成（gousei）資料建置：驗證 tools/gousei_data/<theme>/*.json、計算階段、輸出 static_src/gousei_data_<theme>.js。

執行：
  py -3 tools/gousei_data/build.py              # 建置全部主題
  py -3 tools/gousei_data/build.py wuxia        # 只建置一個主題
  py -3 tools/gousei_data/build.py --check      # 只驗證、不輸出
  py -3 tools/gousei_data/build.py --skeleton   # 不檢查總數與階段分布（只有骨架時用）

階段：初始物體 = 0；其他 = 所有配方中 max(材料階段) + 1 的最小值。
資料格式與驗證規則見 docs/gousei_game_design.md。
"""

from __future__ import annotations

import json
import re
import sys
from collections import Counter
from pathlib import Path

ROOT = Path(__file__).resolve().parent
OUT_DIR = ROOT.parent.parent / "static_src"
ID_RE = re.compile(r"^[a-z0-9_]+$")
MID_TIERS = (3, 4)
HIGH_TIERS = (5, 7)
MIN_MID = 200
MIN_HIGH = 400


def pair_key(a: str, b: str) -> str:
    return f"{a}|{b}" if a <= b else f"{b}|{a}"


def compute_tiers(basics: list[str], recipes: dict[str, str]) -> dict[str, int]:
    tiers = {b: 0 for b in basics}
    pairs = [(key.split("|"), res) for key, res in recipes.items()]
    changed = True
    while changed:
        changed = False
        for (a, b), res in pairs:
            if a in tiers and b in tiers:
                t = max(tiers[a], tiers[b]) + 1
                if res not in tiers or t < tiers[res]:
                    tiers[res] = t
                    changed = True
    return tiers


def load_theme(theme_dir: Path, skeleton: bool = False) -> dict:
    errors: list[str] = []
    meta = json.loads((theme_dir / "theme.json").read_text(encoding="utf-8"))
    cats = {c["id"] for c in meta["categories"]}
    items: dict[str, dict] = {}
    order: list[str] = []

    def add_item(it: dict, cat: str, src: str) -> None:
        iid = it.get("id", "")
        if not isinstance(iid, str) or not ID_RE.match(iid):
            errors.append(f"{src}: 不合法的 id {iid!r}")
            return
        if iid in items:
            errors.append(f"{src}: id 重複 {iid}（已在 {items[iid]['src']}）")
            return
        if not it.get("zh") or not it.get("ja"):
            errors.append(f"{src}: {iid} 缺少 zh 或 ja 名稱")
            return
        items[iid] = {"id": iid, "zh": it["zh"], "ja": it["ja"], "cat": cat, "src": src}
        order.append(iid)

    for b in meta["basics"]:
        add_item(b, "basic", "theme.json")
    for j in meta["junk"]:
        add_item(j, "junk", "theme.json")

    chunks = []
    for path in sorted(theme_dir.glob("*.json")):
        if path.name == "theme.json":
            continue
        chunk = json.loads(path.read_text(encoding="utf-8"))
        own = chunk.get("category")
        if own != "core" and own not in cats:
            errors.append(f"{path.name}: 未定義的分類 {own!r}")
            continue
        for it in chunk.get("items", []):
            cat = it.get("cat", own)
            if cat not in cats:
                errors.append(f"{path.name}: {it.get('id')} 的分類 {cat!r} 未定義")
                continue
            if own != "core" and cat != own:
                errors.append(f"{path.name}: {it.get('id')} 必須屬於分類 {own}")
                continue
            add_item(it, cat, path.name)
        chunks.append((path.name, own, chunk.get("recipes", [])))

    for lang in ("zh", "ja"):
        seen: dict[str, str] = {}
        for iid in order:
            name = items[iid][lang]
            if name in seen:
                errors.append(f"{items[iid]['src']}: {lang} 名稱「{name}」重複（{seen[name]} 與 {iid}）")
            else:
                seen[name] = iid

    recipes: dict[str, str] = {}
    recipe_src: dict[str, str] = {}
    for src, own, rows in chunks:
        for row in rows:
            if not (isinstance(row, list) and len(row) == 3):
                errors.append(f"{src}: 配方格式錯誤 {row!r}")
                continue
            a, b, r = row
            missing = [x for x in (a, b, r) if x not in items]
            if missing:
                errors.append(f"{src}: 配方 {row} 引用不存在的物體 {missing}")
                continue
            if items[r]["cat"] in ("basic", "junk"):
                errors.append(f"{src}: 配方 {row} 的結果不能是初始物體或廢料")
                continue
            if items[a]["cat"] == "junk" or items[b]["cat"] == "junk":
                errors.append(f"{src}: 配方 {row} 的材料不能是廢料")
                continue
            if own != "core":
                if items[r]["cat"] != own:
                    errors.append(f"{src}: 配方 {row} 的結果不屬於分類 {own}")
                    continue
                if own not in (items[a]["cat"], items[b]["cat"]):
                    errors.append(f"{src}: 配方 {row} 至少要有一個材料屬於分類 {own}")
                    continue
                foreign = [x for x in (a, b) if items[x]["src"] not in (src, "core.json", "theme.json")]
                if foreign:
                    errors.append(f"{src}: 配方 {row} 的材料 {foreign} 只能來自本檔、core.json 或初始物體")
                    continue
            key = pair_key(a, b)
            if key in recipes:
                errors.append(f"{src}: 組合 {key} 重複（已在 {recipe_src[key]} 定義為 {recipes[key]}）")
                continue
            recipes[key] = r
            recipe_src[key] = src

    basics = [b["id"] for b in meta["basics"]]
    tiers = compute_tiers(basics, recipes)
    for iid in order:
        it = items[iid]
        if it["cat"] == "junk":
            it["tier"] = 0
        elif iid in tiers:
            it["tier"] = tiers[iid]
        else:
            it["tier"] = None
            errors.append(f"{it['src']}: {iid}（{it['zh']}）無法從初始物體合成")

    normal = [items[i] for i in order if items[i]["cat"] not in ("basic", "junk")]
    hist = Counter(i["tier"] for i in normal if i["tier"] is not None)
    mid = sum(n for t, n in hist.items() if MID_TIERS[0] <= t <= MID_TIERS[1])
    high = sum(n for t, n in hist.items() if HIGH_TIERS[0] <= t <= HIGH_TIERS[1])
    if not skeleton:
        if len(normal) < meta.get("min_items", 0):
            errors.append(f"物體數 {len(normal)} 少於 {meta['min_items']}")
        if mid < meta.get("min_mid", MIN_MID):
            errors.append(f"階段 3〜4 的物體 {mid} 種，少於 {meta.get('min_mid', MIN_MID)}")
        if high < meta.get("min_high", MIN_HIGH):
            errors.append(f"階段 5〜7 的物體 {high} 種，少於 {meta.get('min_high', MIN_HIGH)}")

    per_file = Counter(i["src"] for i in normal)
    stats = {"items": len(normal), "recipes": len(recipes), "mid": mid, "high": high,
             "tiers": dict(sorted(hist.items())), "per_file": dict(sorted(per_file.items()))}
    return {"meta": meta, "items": [items[i] for i in order], "recipes": recipes, "errors": errors, "stats": stats}


def render_js(theme: dict) -> str:
    meta = theme["meta"]
    data = {
        "id": meta["id"],
        "name": meta["name"],
        "basics": [b["id"] for b in meta["basics"]],
        "junk": [j["id"] for j in meta["junk"]],
        "categories": meta["categories"],
        "items": [[i["id"], i["zh"], i["ja"], i["cat"], i["tier"]] for i in theme["items"]],
        "recipes": dict(sorted(theme["recipes"].items())),
    }
    body = json.dumps(data, ensure_ascii=False, separators=(",", ":"))
    return (
        "// 由 tools/gousei_data/build.py 產生，請勿手動修改；原始資料在 tools/gousei_data/<theme>/。\n"
        f"(window.PriTestGouseiData = window.PriTestGouseiData || {{}})[{json.dumps(meta['id'])}] = {body};\n"
    )


def main(argv: list[str]) -> int:
    check = "--check" in argv
    skeleton = "--skeleton" in argv
    names = [a for a in argv if not a.startswith("--")]
    dirs = [ROOT / n for n in names] if names else sorted(p.parent for p in ROOT.glob("*/theme.json"))
    failed = False
    for d in dirs:
        theme = load_theme(d, skeleton=skeleton)
        print(f"[{d.name}] {json.dumps(theme['stats'], ensure_ascii=False)}")
        if theme["errors"]:
            failed = True
            print(f"[{d.name}] {len(theme['errors'])} 個錯誤：")
            for e in theme["errors"][:300]:
                print("  " + e)
            continue
        if not check:
            out = OUT_DIR / f"gousei_data_{theme['meta']['id']}.js"
            out.write_text(render_js(theme), encoding="utf-8")
            print(f"[{d.name}] 已輸出 {out}")
    return 1 if failed else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```python
import pathlib
import random

    a, b = key.split("|")
    t = max(by[a]["tier"], by[b]["tier"])
    if res not in best or t < best[res][0]:

    if by[x]["tier"] > 0:
        for y in best[x][1].split("|"):
            show(y, depth + 1)

    show(target["id"])
    print()
```

```python
GOUSEI_SCRIPTS: tuple[str, ...] = (
```

```js
  function el(tag, attrs, children) {
    var node = document.createElement(tag);
    Object.keys(attrs || {}).forEach(function (k) {
      var v = attrs[k];
      if (v === null || v === undefined || v === false) return;
      if (k === "text") node.textContent = v;
      else if (k === "class") node.className = v;
      else if (k.indexOf("on") === 0) node.addEventListener(k.slice(2), v);
      else if (v === true) node.setAttribute(k, "");
      else node.setAttribute(k, v);
    });
    (children || []).forEach(function (c) {
      if (c === null || c === undefined) return;
      node.appendChild(typeof c === "string" ? document.createTextNode(c) : c);
    });
    return node;

  // 遊戲資料只有 zh / ja；en 依專案慣例 fallback 至 ja

    if (catId === "basic") return t("gs_cat_basic");
    if (catId === "junk") return t("gs_cat_junk");
    var c = theme.catById[catId];
    if (!c) return catId;
    return lang() === "zh" ? c.zh : c.ja;
  }

  function playerById(id) {
    for (var i = 0; i < state.players.length; i++) if (state.players[i].id === id) return state.players[i];
    return null;

  function loadTheme(themeId, cb) {
    if (themes[themeId]) { cb(null, themes[themeId]); return; }

      var data = window.PriTestGouseiData && window.PriTestGouseiData[themeId];
      if (!data) { cb(new Error("no-data")); return; }
      themes[themeId] = Core.indexTheme(data);
      cb(null, themes[themeId]);
    }
    if (window.PriTestGouseiData && window.PriTestGouseiData[themeId]) { ready(); return; }
    var src = app.getAttribute("data-src-" + themeId);

    s.src = src;
    s.onload = ready;
    s.onerror = function () { cb(new Error("load-failed")); };

  // ---------------- 設定畫面 ----------------

      if (state.mode === "shared") app.appendChild(renderTargetsPanel(theme));
      app.appendChild(renderSlots(theme));

    app.appendChild(progressPanel());
    if (!state.winner) app.appendChild(renderPool(theme));
    app.appendChild(renderLog(theme));
    app.appendChild(renderFooter());
  }

  function renderJoin() { app.appendChild(el("p", { class: "gs-error", text: t("gs_join_invalid") })); }

    app.innerHTML = "";
    if (join) { renderJoin(); return; }
    if (!state) { renderSetup(); return; }
    var theme = themes[state.themeId];
    if (!theme) {
      app.appendChild(el("p", { class: "gs-muted", text: ui.error || t("gs_loading") }));

    if (state.mode === "shared" && ui.handoff && !ui.lastEntry && !state.winner) { renderHandoff(); return; }
    renderPlay(theme);
  }

  function init() {
    var params = new URLSearchParams(window.location.search);
    if (params.has("join")) {
      join = Core.parseJoin(params.get("join")) || { invalid: true };

      return;

      loadTheme(state.themeId, function (err) {
        if (err) ui.error = t("gs_load_failed");
        render();
      });
    }
    render();
  }

  window.addEventListener("i18n:change", render);
  window.PriTestGousei = {
    _debugState: function () { return state ? JSON.parse(JSON.stringify(state)) : null; },
    _theme: function () { return state ? themes[state.themeId] : null; }
  };
  init();
})();
```
