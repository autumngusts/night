# 明星經紀 starV：遊玩時程與動圖圖鑑「御三家」規格

2026-11-15 建立。上層規格：`docs/superpowers/specs/2026-10-27-starv-design.md`。

---

## 1. 遊玩時程（難度量測）

### 1.1 量測方式

- 時間模型：現實 1 分鐘＝遊戲 1 天（`BAL.dayMs = 60000`），遊戲 1 年≈現實 6 小時；離線最多補 480 天（8 小時）。
- 用 `tools/starv_check/sim.js` 的經營策略（積極經營／自動方針），另外載入擴充系統（季度目標等），各跑 6 個 seed、20 年，記錄各里程碑第一次達成的遊戲日，取中位數。
- 「累計時間」＝遊戲時鐘實際跑的時間。「每天開 1 次」是指玩家一天只登入一次、每次補 8 小時時，大約要經過幾天。

### 1.2 結論

- **這款主要卡的是時間，操作好壞影響不大**：積極經營與全自動方針的進度幾乎相同（Lv10 分別在 86.0h／86.5h）。
- **一整局＝公司 Lv10 → 發動新紀元，約 86 小時遊戲時間**。每 8 小時內回來一次的玩家約實際 4〜5 天；每天只開 1 次的玩家約 11 天。

### 1.4 限制

- 模擬是 bot 每天最佳化操作，重大事件都套預設選項。真人第一小時要學操作，新手期大約慢 1.5〜2 倍；但公司等級與頒獎這類靠時間的里程碑幾乎不受影響。
- 目前沒有新手教學流程。

## 2. 動圖圖鑑「御三家」（第一期）

### 2.1 角色與動作

- 御三家 3 位，每位 3 個動作（webm），資料在 `static_src/starv_motion_data.js` 的 `D.MOTION.STARTERS`。
- 換上正式動畫：webm 放進 `static_src/images/starv/motion/`，在每個動作的 `src` 填相對於 `static/` 的路徑（例：`images/starv/motion/s1_1.webm`）。名字、介紹、動作名稱也在同一檔修改。
- 靜止圖（png／webp）：角色的 `still`＝選擇畫面卡片的立繪；動作的第 3 個參數＝圖鑑縮圖（省略時用角色的 `still`）。
  - 選擇畫面沒有 `still` 時，改用動作 1 webm 的第一格；連 webm 都沒有就顯示圖示。
  - 圖鑑縮圖不建立會播放的 `<video>`（一次 9 格太重），只放靜止圖，點開才播放。
- `src` 是空字串時，圖鑑顯示「動畫準備中」佔位畫面；載入失敗也會退回佔位畫面。
- ID（`s1`／`s2`／`s3`）存在玩家存檔裡，上線後不要改。第二期角色往後追加新 ID。

### 2.2 解鎖規則（每一局各自判定，已解鎖的永久保留）

| 階段 | 觸發條件 | 本局夥伴（開局選的那位） | 其他兩位 | 預估時間 |
| --- | --- | --- | --- | --- |
| 1 | 開局選擇御三家 | 動作 1 | — | 0 分 |
| 2 | 本紀元第 1 次頒獎典禮結束（`st.awards.history` 有紀錄） | 動作 2 | 動作 1 | 6.0h（固定） |
| 3 | 階段 2 之後，公司 Lv5（`D.MOTION.midLevel`） | 動作 3 | 動作 2 | 約 9h |

- **其他兩位的動作 3** 只能在之後的局（新紀元或重新開始）選它們當夥伴，到階段 3 才拿得到。全收藏至少要 3 局。
- 階段 3 需要先經過階段 2：即使頒獎前就到 Lv5，也要等頒獎典禮之後才解鎖。
- 只升不降：之後的局選了已經有動作的角色，不會倒退。

### 2.3 「一局」的定義

- **新紀元**（公司 Lv10 後發動）：`newEra` hook 把 `pick` 清空，要求重新選擇；階段依新紀元的頒獎紀錄與公司等級重新判定。
- **重新開始**（公司分頁的重置存檔）：存檔被清空，但解鎖等級另外鏡射在 `localStorage["pritest-starv-motion"]`，新存檔建立時取較高者併回。
- 舊存檔第一次載入時也會彈出選擇視窗；如果已經過了頒獎或 Lv5，選完會立即補齊對應的階段。

### 2.3.1 開局選擇（兩步驟）

1. 三張卡片顯示靜止圖、名字、介紹（之後的局會顯示已解鎖幾個動作）。
2. 點進其中一位：播放動作 1，下方「← 返回」或「確定選擇 ○○」。按確定之前不會選定。

視窗不能用點背景關閉，一定要選一位。

### 2.3.2 本命彈出

- 一般遊戲中，每過 1 分鐘（現實時間，`D.MOTION.popupEveryMs = 60000`），在**遊戲畫面目前看得到的範圍**右下角播放本命（本局夥伴）**目前最高等級**的動作。
- 播放 `popupLoops = 2` 輪後淡出關閉，再重新計時 1 分鐘。
- 大小：依影片原始比例，面積最多佔可見遊戲畫面的 `popupArea = 1/4`（高度最多 75%、寬度最多 60%），貼右下角留 8px。
- 不擋操作：`pointer-events: none`，點擊會穿透到底下的按鈕；z-index 低於所有視窗。
- 順延條件：有視窗開著（選擇、事件、頒獎等）、3D 演出的右下角短片正在顯示時，每秒重試；分頁在背景時不播並重新計時；雲端唯讀時不播。
- 本命最高等級的動作還沒有 webm 時，略過這一輪。
- 掛在 `body` 上（`#sv-app` 每次重畫都會清空），捲動或縮放視窗時重新定位。

### 2.4 存檔結構

```js
st.codex.motion = {
  lv: { s1: 0〜3, s2: 0〜3, s3: 0〜3 },   // 已解鎖到第幾個動作
  pick: "s2" | null,                       // 本局夥伴；null＝尚未選擇
  pickEra: 1,                              // 選擇時的紀元
  picks: [{ era, id }]                     // 歷次選擇紀錄
}
```

放在 `st.codex` 底下，所以新紀元會保留（`newEra` 保留 `codex`），也會跟著雲端存檔、匯出入一起走。

### 2.5 成就（`starv_achievements_4.js`）

| ID | 名稱 | 條件 | 星探券 |
| --- | --- | --- | --- |
| `motion_first` | 第一支動圖 | 解鎖 1 個動作 | 2 |
| `motion_trio_full` | 看家本領 | 1 位御三家 3 個動作全解鎖 | 5 |
| `motion_all` | 御三家全收藏 | 9 個動作全解鎖 | 10 |

判定類型 `motions`／`motionFull` 由 `starv_motion.js` 透過 `Core.achCheck(type, fn)` 登記。

### 2.6 檔案

| 檔案 | 內容 |
| --- | --- |
| `static_src/starv_motion_data.js` | 御三家資料（名字、介紹、顏色、動作與 webm 路徑）、`midLevel` |
| `static_src/starv_motion.js` | 解鎖邏輯（純邏輯、可在 node 載入）：`ensure`／`stage`／`sync`／`choose`／`merge` |
| `static_src/starv_motion_ui.js` | 開局選擇視窗（兩步驟）、殿堂分頁「動圖」子分頁、播放視窗、本命彈出、解鎖提示、localStorage 鏡射 |
| `static_src/starv_achievements_4.js` | 動圖成就 3 項 |
| `tools/starv_check/motion_check.js` | 三局完整解鎖流程、成就、鏡射合併、舊存檔遷移的檢查 |

驗證：`node tools/starv_check/motion_check.js`。

### 2.7 第二期預留
