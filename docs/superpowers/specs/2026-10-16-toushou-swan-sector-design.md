## 1. 開局設定

| 設定 | 說明 | 預設 |
| --- | --- | --- |
| `blackSwanEnabled` | 啟用黑天鵝事件卡 | 關 |
| `sectorLinkEnabled` | 啟用板塊連動 | 關 |

兩者互相獨立，也和風向卡、任務卡、加減分方式互相獨立。舊存檔缺欄位視為關。

## 2. 黑天鵝事件卡

### 2.1 牌堆

7 張：5 張事件＋2 張「平靜」。開局洗牌（使用 state 內的 PRNG），每個標的抽 1 張，牌堆用完時重新建立並洗牌。

### 2.2 翻開時機

全員下注完成、進入第一位股東的回合**之前**自動翻開，**公開**顯示在標的卡上直到本標的結算。不新增階段。

### 2.3 效果

n＝本標的的股東人數（＝玩家人數），消息依序編號 1～n。

| id | 名稱 | 效果 |
| --- | --- | --- |
| `circuit` | 熔斷 | 每一則消息的加減分限制在 −10～＋10 |
| `hype` | 題材炒作 | 第 1 則消息的加減分 ×2 |
| `whale` | 主力進場 | 第 n 則消息的加減分 ×2 |
| `exright` | 預告除權 | 第 ⌈n/2⌉ 則消息套用後，價格回到 100 |
| `exhausted` | 利多出盡 | 第 n 則消息的加減分正負反轉 |
| `calm` | 平靜 | 無效果（2 張） |

### 2.4 計算順序

1. 原始加減分：主持人輸入（輸入時仍受風向卡正負限制），或投票平均四捨五入後套用風向歸 0。
2. 事件卡修正：`hype`／`whale` 乘 2、`exhausted` 乘 −1（只在對應的那一則）。
3. `circuit`：夾在 −10～＋10。
4. 價格＝max(0, 價格＋最終加減分)。
5. `exright`：若這是第 ⌈n/2⌉ 則，價格設為 100。

消息紀錄 `news[i]`：
- `delta`：最終加減分（任務「自己的消息造成的漲跌幅」讀這個值）。
- `rawDelta`：只有事件卡修正過時才有，記錄步驟 1 的值。
- `priceAfter`：步驟 4 的價格。
- `exRight: true`：觸發除權時記錄；此時價格變為 100。

消息面在修正過的消息顯示「原始 → 最終」與事件名稱，除權顯示「除權 → 100」。

## 3. 板塊連動

- 開始下注（`startBetting`）時決定本標的起始價：
  - 本局歷史中有同類別的已結算標的 → 取**最近一個**的最終價 F，起始價＝max(0, 100＋round((F−100)×0.5))，round 為四捨五入、.5 遠離 0。
  - 沒有 → 100。
- `current.startPrice` 記錄起始價，`current.price` 從起始價開始；歷史紀錄也寫入 `startPrice`。
- 未啟用時起始價一律 100（行為與現在相同）。
- 自訂標的同樣依其類別連動。
- 下注畫面：顯示起始價；預測價格輸入框預設值改為起始價。標的卡在起始價不是 100 時註明「板塊連動：上一個同類別標的最終 F」。

## 4. 規則引擎修改（`toushou_core.js`）

- `config.blackSwanEnabled`、`config.sectorLinkEnabled`。
- `state.swanDeck`（開局建立）；`current.event`（id 或 `null`）、`current.startPrice`。
- 資料：`toushou_data.js` 新增 `SWAN_CARDS`（id、名稱 zh/ja、說明 zh/ja）與 `SWAN_COMPOSITION`。
- 新增純函式 `sectorStartPrice(state, category) -> number`、`applyEvent(event, turnIndex, n, delta) -> { delta, modified }`（供 UI 預覽與檢查）。
- `placeBet` 全員下注完成時抽事件卡；`commitDelta` 依 2.4 套用。
- `history[i]` 新增 `startPrice`、`event`。

## 5. UI 修改（`toushou.js`）

- 開局設定兩個勾選框。
- 標的卡：顯示事件卡（名稱＋說明）與起始價註記。
- 消息面：原始→最終、除權標示。
- 下注：預測價預設值＝起始價。
- 結算與整局回顧：每個標的顯示起始價與事件。

## 6. i18n

`zh`、`ja` 新增 key；`en` fallback。

## 7. 驗證

1. `core_check`：牌堆組成 5＋2 與重洗；各事件在正確的那一則生效、其他則不受影響；熔斷夾值；除權後價格 100；計算順序（風向歸 0 之後才翻倍／反轉，熔斷最後）；投票與主持人兩種模式都適用；板塊連動公式（160→130、40→70、45→72（−27.5 遠離 0 進位為 −28）、只看最近一個同類別、無同類別→100、未啟用→100）；舊存檔缺欄位。
2. `ui_check`：既有兩局維持通過；新增一局啟用黑天鵝＋板塊連動、2 個同類別標的，檢查起始價與事件顯示。
3. `multi_device_check`：維持通過（設定不變）。
