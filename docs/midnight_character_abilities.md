# midnight 10 名角色的能力／技能／技藝運作整理（2026-09-21）

目的：把 `static_src/character_types.js` 的 10 個角色類型（暗黑／黎明變體與本體共用同一組
Lv1 能力／Lv2 技能／Lv3 技藝，只差遺物效果群組）在 midnight（即時制）裡**實際怎麼運作、
會產生多少數值**逐項列出。所有數字都是從 `static_src/midnight.js` 目前的程式碼讀出來的，
不是規則書的回合制原文；「規則書原文」欄只摘要重點，完整本文見 `character_types.js`。

§11 是整理時發現的落差與 2026-09-21 的裁定結果，§12 是同日實作的能力特效一覽。

## 0. 通則（所有角色共用）

### 0.1 習得等級與入口

| 種類 | 習得等級 | 操作入口 | 備註 |
| --- | --- | --- | --- |
| Lv1 能力（`type.abilities[0]`） | 一開始就有 | 依種類：被動自動觸發／角色視窗開關／右下專用鍵 | 各自有獨立冷卻欄位，不吃下面的技能／技藝冷卻規則 |
| Lv2 技能（`type.skills[0]`） | **Lv2** | 右下［技能］鍵（`#btn-midnight-character-skill`） | 未達等級鍵不顯示，強按會跳「Lv2 才能使用」 |
| Lv3 技藝（`type.arts[0]`） | **Lv3** | 右下［技藝］鍵（`#btn-midnight-art`） | 同上（Lv3） |

### 0.2 冷卻（取代規則書的「使用次數」）

| 項目 | 數值 | 出處 |
| --- | --- | --- |
| 技能冷卻 | **60 秒**（守護者「旋風」、復仇者「召喚靈體」例外：10 秒） | `SKILL_COOLDOWN_MS`／`MIDNIGHT_ABILITY_COOLDOWN_OVERRIDE_MS` |
| 技藝冷卻 | **180 秒** | `ART_COOLDOWN_MS` |
| 擊破敵人時 | 技能冷卻 −5 秒、技藝冷卻 −10 秒（只在冷卻中才扣，不會扣成負的） | `grantKillCooldownReduction()` |
| 換日 | 技能／技藝冷卻立即歸零 | `resetAbilityCooldowns()` |
| 詞條「HP未滿時アーツゲージ蓄積鈍化」 | HP 未滿時冷卻時間 ×(1＋N%) | `useCharacterAbility()` |
| 冷卻中的額外使用 | 送葬人「力量感應」credit／恩寵「大ルーンの虚像」技藝蓄積／遺物「技能使用次數＋1」技能蓄積，三者都能在冷卻中再用一次 | 同上 |

按鈕上的冷卻進度用圓形 conic-gradient 順時針掃一圈（`.midnight-cooldown-dial`）。

### 0.3 傷害怎麼算（技能／技藝共用）

```
本文【總合傷害：N】
  → N ＋ 護符技能加成（劍蠍護符 HP滿時+5／緋色七刃 低HP時+5）
      ＋ 無賴漢「鬥爭心」（HP 未滿時 +20）
      ＋ 執行者「不撓」堆疊 ×10
      ＋ 遺物專屬加成（目前只有追蹤者「技藝強化（燃燒）」+50）
  → ×3（CHARACTER_ABILITY_DAMAGE_MULT，只乘在實際傷害，toast 顯示原值）
  → damageCombatTarget()：
      × 詞條傷害倍率 → 血魂之歌中 ×1.5 → 單人模式 ×2
      → 先扣雜兵 HP，溢出的部分才打敵人本體
      → 敵人本體依「HP價值」百分比減傷（鐵眼「標記」中 −10）、四捨五入後最低 1 點
```

* 本文的 **▲／◆** 在技能／技藝**不計入傷害**，只當「削韌」符號：▲＝0.5、◆＝1，每滿 3 點
  敵人 Guard Point −1（`recordGuardReductionForPoint()`）（2026-09-21 使用者確認維持）。
* 本文沒有【總合傷害：N】（例：爪擊、旋風、終曲）→ 不造成傷害，只 toast 規則原文＋套用
  下面各角色列出的「midnight 專屬效果」。
* 本文帶【復歸傷害：N】且在白名單（襲擊之楔／救世之翼／一擊必殺／圖騰・史黛拉）→
  自動對第一位瀕死隊友累積 N 點復歸進度；其餘招式的復歸傷害不自動觸發。
* 「對雜兵造成 HP損害：■」的句子在技能／技藝**不另外解析**（雜兵本來就會先吃到上面的
  ×3 傷害）；只有遺物追加效果那幾條有明寫雜兵傷害（1■＝`MOB_DAMAGE_PER_RULEBOOK_POINT`＝100）。

### 0.4 「直到階段結束」的換算

一律 **10 秒**（`midnight-phase-to-realtime-conversion`），後放的覆蓋前一個、時間不相加。
全隊共用的 buff 寫在 `meta`（所有裝置各自判斷時限），自身 buff 寫在 `character/{tokenId}/_xxxUntil`。
