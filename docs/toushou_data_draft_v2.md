# 東正小遊戲（toushou）資料擬稿 v2：標的擴充＋全面改寫（審核用）

狀態：擬稿，待使用者審核。確認後補上日文並轉成 `static_src/toushou_data_*.js`。
前版：`docs/toushou_data_draft.md`（v1）。本版取代 v1 的標的簡介、特徵、切入點與所有消息牌內容。

撰寫方針（v2）：
- **簡介＝滿分說明**：抽到時要讓人覺得「這個標的完美到不行」，用最高級、最誇張的讚美語氣；股東再放消息往下砸。
- **特徵、切入點要有梗、貼近最近的新聞話題**，方便大家想消息。
- 新增的標的以 ★ 標示。
- 專屬牌：每類 6 張（▲1、▼4、◆1），`{target}` 代入標的名稱。

規模：17 類別、190 標的（現有 66＋新增 124）、新類別專屬牌 36 張。

> 時事類內容（巡演、總部、重建進度等）依撰寫時所知的資訊撰寫，定稿前請再確認。
