# 黃牌 新英雄（6 位）：規則、卡表與平衡紀錄

2026-10-24 使用者指定新增英雄：忍者、劍豪、陰陽師、海賊、舞孃、咒術師。
2026-10-24 使用者確認「照這份做」後實作完成。下面的卡表是從遊戲的卡牌說明產生器輸出的（和遊戲裡顯示的文字一致），數值已含實作後的平衡調整。
規則程式在 `static_src/yellow_core.js`（搜尋「2026-10-24 新英雄」），資料在 `static_src/yellow_data.js`，畫面在 `static_src/yellow.js` 的 `newHeroBadges()`、`fxText()`。

## 共通規則（和現有 13 位一樣）

- 每位：起始牌組 8 張＋三條成長方向，各 12 張（普通 3／進階 5／高階 4）。
- 費用、傷害的尺度沿用現有：1 費約 6～7 傷害或 5～6 護盾；進階 2 費約 12～14；高階明顯更強。
- 「近」＝只打內圈、「遠」＝只打外圈、「任」＝都可以；「範圍」＝指定範圍圈（`tgt: "area"`）；「全內圈／全場」＝全範圍招。
- 「能力」＝打出後整場有效（`pow`）。「消耗」＝打出後這場戰鬥移出牌組。
- 數值經過 AI 對局（`balance_check.js`、`path_check.js`）調整，結果見最後一節。
- 首領免疫「魅惑」（舞孃）。
- 美術：還沒有圖，暫時用 SVG 剪影＋emoji；角色描述的提示詞已寫在 `docs/yellow_art_guide.md`。

和現有英雄的區隔：

- **忍者**：快速出很多張牌。和賭徒、遊俠都不同，靠「本回合出了幾張」。
- **劍豪**：一擊與反擊。和武僧的氣不同：劍意只加在下一擊，不靠消耗資源觸發效果。
- **陰陽師**：靠出牌順序。式神只有一隻、會升級，和召喚師一大群精靈不同。
- **海賊**：彈藥管理加打倒獎勵。
- **舞孃**：攻擊、技能交替出牌。魅惑是控場，不是吟遊詩人的增益。
- **咒術師**：吃傷害換力量。和女巫的毒與削弱完全不同，沒有中毒，也沒有「詛咒」削弱。

## 陰陽師 ☯️

**定位**：照順序出牌。式神是穩定的輸出，結界替隊伍減傷。

**新規則**

- 五行：每張卡都有屬性 `el`，分成木🌳、火🔥、土⛰️、金⚙️、水💧，卡面角落會顯示。
- 相生：順序是木 → 火 → 土 → 金 → 水 → 木。打出的牌如果是「上一張打出的牌所生」，例如上一張是木、這張是火，就算相生成立，觸發卡上的「相生：」效果（`gen`）。
  - 上一張的屬性記在 `h.lastEl`，跨回合也接得上。
  - 本回合相生成立的次數記在 `h.genN`。
- 被動「陰陽調和」`pw.genBlk`：相生成立時 +3 護盾（聖地強化 +1）。
- 式神 `h.shiki`：等級 0～5，0 表示沒有。回合結束時攻擊一個隨機敵人，傷害 5×等級（`D.SHIKI_DMG`）。
  - 「召喚」：等級至少變成 1。
  - 「強化」：等級 +1。
- 結界 `h.kek`：每次受到攻擊時傷害 −n，到自己下回合開始時歸零；可以給隊友。

## 咒術師 🪆

**定位**：受傷會變強（咒力）；用人偶把自己受的傷轉給敵人；用束縛換爆發。

**新規則**

| 名稱 | 規則 |
| --- | --- |
| 咒力 `h.ce` | 最多 10；每次生命實際減少（被打或自傷）+3。 |
| 被動「咒力循環」`pw.ceHit` | 就是上面這條；聖地強化 +1。 |
| 咒力 k（`ceIf`） | 消耗 k 咒力才發動追加效果。觸發方式和武僧的氣一樣，來源完全不同：武僧靠出攻擊牌、咒術師靠受傷。 |

### 和草案不同的地方（平衡調整）

草案的數值實作後依 `path_check.js`（各方向 10 局，搭固定強隊友）與 `balance_check.js`（隨機隊伍）調了幾輪：

- 分方向檢查時新英雄看起來正常，但隨機隊伍裡全部偏弱（3～10/30，現有英雄多在 14～26/30）。主因是基本牌組比現有英雄弱（基本護盾 5，現有多為 6），所以：
  六位的基本護盾 5 → 6、基本攻擊 +1，HP 與被動也調高（見一覽）。
- 忍者：暗殺、忍術偏弱 → 背刺、暗殺、千鳥、火遁、煙玉、分身、忍法・百鬼加強。
- 劍豪：居合偏強 → 一閃 24 → 20、踏込劍意 3 → 2、無念無想 +6 → +4。
- 陰陽師：AI 不會照順序出牌，五行偏弱 → AI 評分加上「手上有下一張能相生的牌」；式神每級 4 → 5；結界 3 → 4。
- 海賊：開戰彈藥 3 → 4、火槍 10 → 11、填彈多抽 1 張。
- 舞孃：魅惑偏強 → 秋波改 1 費（易傷 2）、傾國／傾城之姿改 3 費、心之囚魅惑 3 → 2、薔薇 7 → 6；劍舞、迴旋加強。
- 咒術師：束縛方向 AI 用「縛・命懸」把自己耗死 → 自傷量調低（命懸 10 → 5、血誓 6 → 4、極之番 3 → 1），縛・借時下回合只扣 1 魔力；人偶方向的綁定、護盾加強。
