## 1. 生涯養成（育成）

### 1.1 流程概要

1. 犬舍新增「🎓 生涯養成」：選犬種、取名、（有血統書時）選 2 隻祖先。
2. 一趟生涯＝ **24 回合**（Q3 已確認），分 3 年：幼犬期（1〜8）、青年期（9〜16）、成犬期（17〜24）。
3. 每回合選一個行動：訓練（5 種）／休息／外出（玩耍）／出賽。
4. 每年底有**目標賽**（第 8、16、24 回合），沒達成＝生涯提前結束（仍可畢業，但評分低）。
5. 第 24 回合的最終目標賽結束後畢業：顯示評分（沿用 `SK.rating` 的 G〜SS），可以把狗收進犬舍（犬舍滿了要先送養一隻），並自動寫入血統書（產生因子）。

同時只能有一趟進行中的生涯，存在犬舍資料（`Kennel.load().career`），隨時可以中斷、下次接著玩。

### 1.2 狀態

| 欄位 | 說明 |
| --- | --- |
| `turn` | 第幾回合（1〜24） |
| `stats` | 8 項能力（起點＝犬種基礎＋祖先的藍因子加成） |
| `energy` | 體力 0〜100（和犬舍的「疲勞」分開；訓練消耗、休息回復） |
| `mood` | 調子 0〜4（沿用 `D.MOODS`；影響訓練成長 ×0.8〜1.2） |
| `facLv` | 5 種訓練各自的等級 1〜5（同一種練 4 次升一級，成長量 +10%／級；參考「施設レベル」） |
| `sp` | 技能點（比賽、事件取得，用來學技能） |
| `hints` | 技能提示：{ 技能 id: 折扣等級 }（事件與繼承取得，學習時打折） |
| `skills` | 已學技能（欄位上限沿用金 1、罕見 2、一般 2） |
| `goals` | 3 個目標賽的達成狀況 |
| `log` | 每回合紀錄（畢業時顯示） |

### 1.3 訓練（每回合一種）

把現有 9 種訓練歸成 5 個生涯訓練（主能力＋2 項次能力），讓選擇比較集中：

| 生涯訓練 | 主 | 次 |
| --- | --- | --- |
| 衝刺（速度） | 速度 | 力量、敏捷 |
| 長跑（耐力） | 耐力 | 速度、專注 |
| 拉輪胎（力量） | 力量 | 耐力、跳躍 |
| 障礙（敏捷） | 敏捷 | 跳躍、接物 |
| 水上與服從（技巧） | 游泳 | 接物、專注 |

- 成長＝基礎值 × 訓練等級 × 調子 ×（體力 < 30 時 ×0.8）；之後依實測調整（§3.6）。
- **失敗率**：體力越低越高（體力 50 以上 0%，0 時約 40%）。失敗＝能力小幅下降、調子 −1，低機率「受傷」（下 2 回合不能訓練）。這是養成的主要風險，要靠休息管理。
- 每次訓練消耗體力約 20，休息回復約 50（低機率睡過頭只回 30）。

### 1.4 出賽

- 生涯中的比賽直接用現有的關卡賽／真賽狗模擬（`Core.makeCard`＋`Core.simulate`），畫面沿用出賽表與 3D 轉播，加「跳到結果」。
- 目標賽：第 8 回合新手戰前 3 名、第 16 回合一般戰前 3 名、第 24 回合重賞第 1 名（**依實測再調**）。
- 自選比賽：消耗體力約 15、得技能點與少量能力；連續出賽調子容易下降。
- 生涯中可不可以下注：**待確認 Q4**。建議：不能下注（像練習賽），避免用生涯刷錢。

### 1.5 事件

- 每回合結束後機率發生（約 35%），從事件表抽：純加成（+能力／+體力／+調子）、二選一（例：「要不要追那隻貓？」→ 敏捷 +5，或體力 −10 但得到技能提示）、技能提示。
- 事件文字放在 `saigo_career.js` 的資料（雙語 `C(zh, ja, en)`），內容依犬種體型、目前調子篩選。
- 第一版約 30 個事件，之後再擴充。

### 1.6 技能

- 技能點在生涯中任何時候都能用來學技能：價格＝一般 120／罕見 200／金 360 點，提示每級折 10%（最多 30%）。
- 可學的範圍＝有提示的技能＋每個生涯開始時抽一份「生涯技能表」（金 2、罕見 6、一般 10）。
- 不會用到犬舍的 30 分鐘技能池。

## 2. 血統繼承（因子）

### 2.1 畢業時產生因子

每隻畢業（或從犬舍送養／退役）的狗依最後能力產生因子：

| 種類 | 內容 | 星數 |
| --- | --- | --- |
| 藍（能力） | 速度／耐力／力量／敏捷 其中一種（依最高的那項，有隨機） | ★1〜3：依該能力的高低與亂數 |
| 紅（適性） | 一種跑法（逃／先／差／追），或一種地形適性（公園、森林、雪山、沙漠、海灘） | ★1〜3 |
| 白（技能） | 學過的技能中隨機 0〜3 個，各 ★1〜3 | — |

- 地形適性是新概念：目前只有天氣耐性與跑法適性。**待確認 Q5（範圍）**：只做跑法紅因子，或連地形適性一起做（要改 `effStats` 加地形加成）。建議第一版只做跑法。
- 送養沒經過生涯的舊狗也能留因子（依它的能力換算），但星數較低，讓舊存檔也有血統可用。

### 2.2 血統書

- 新畫面「📜 血統書」：最多 30 筆（超過時要刪），每筆有名字、犬種、評分、因子、戰績與稱號。
- 犬舍的狗可以「退役進血統書」（取代單純送養；原本的送養按鈕保留，送養也會寫進血統書）。

### 2.3 繼承

- 開始生涯時選 2 隻祖先（可以不選）。祖先的祖先（祖父母）因子也算，但效果減半（只往上一代，存在血統書的 `parents` 欄位）。
- 開始時：每個藍因子 ★ 給初始能力 +5／+12／+20；紅因子提高對應跑法的適性一階（例：B → A）。
- 第 9、17 回合各有一次「繼承事件」：每個因子依星數機率觸發（★1 約 30%、★3 約 70%），藍因子再加能力、白因子給技能提示。
- 犬種：**待確認 Q6**。建議照賽馬娘：犬種自由選，祖先只給因子；另一個選項是「幼犬的犬種從祖先中選」（偏向配種模擬，限制較多）。

### 2.4 （之後再做）和朋友借血統

- 用分享碼（沿用 `games.js` 的 base64url JSON 編碼）匯出／匯入一筆血統書資料，當作「借用的祖先」（每趟生涯 1 隻）。
- 連線房間裡直接借用其他玩家的狗當祖先。

## 3. 技術規劃

### 3.2 資料（存在 `pritest-saigo-kennel`）

- `store.career`：進行中的生涯（§1.2）。
- `store.lineage`：血統書陣列。
- 犬舍的狗新增 `d.career`（畢業資訊：評分、生涯技能、目標達成）、`d.factors`、`d.parents`；`entry()` 對生涯狗用畢業時的能力，技能不套用期限。

### 3.3 比賽整合

- 生涯比賽在 `ui.career` 模式下用現有的出賽表與比賽畫面；結算走 `settle()` 的分支（不下注、不進錢包、不算犬舍戰績，結果回寫生涯狀態）。
- 生涯中不出現宿敵（或只在目標賽出現，**之後再定**）。

### 3.4 平衡與 CPU

- 先寫 Node 模擬：用「自動玩家」（固定策略：體力 < 45 就休息、其餘挑訓練等級最高的訓練、目標賽前休息）跑 500 趟生涯，量畢業能力總量、評分分布、目標達成率。
- 目標：一般玩家畢業約 A／A+，練得好的約 S；能力總量約 20 次訓練的 1.3〜1.6 倍。
- 關卡賽 CPU 加「玩家實力下限」補強（同真賽狗 NPC 的做法），避免生涯狗輾壓。重跑 `core_check.js` 的賠率校準與跑法平衡。

### 3.5 測試

- `tools/saigo_check/core_check.js` 新增：訓練成長／失敗率邊界、事件確定性（用 seed）、目標判定、因子產生與繼承加成、存檔相容（舊犬舍資料載入）。
- 新增 `tools/saigo_check/career_check.js`（Playwright）：完整跑一趟生涯（加速）→ 畢業收進犬舍 → 出賽 → 退役進血統書 → 用它當祖先開新生涯，確認初始加成與繼承事件。

### 3.6 分階段實作

| 階段 | 內容 | 可以單獨上線？ |
| --- | --- | --- |
| A | `saigo_career.js` 計算核心＋自動玩家平衡模擬 | 否（只有測試） |
| B | 生涯畫面（回合、訓練、休息、外出、事件、技能商店、目標賽、畢業收進犬舍） | 是：沒有繼承的生涯養成 |

| D | CPU 補強、平衡微調、文件與檢查 | 和 B／C 一起 |
| E | 分享碼借用血統、連線房間借用 | 之後再做 |

建議 A＋B＋D 先做一版推上去試玩，手感確認後再做 C。

## 4. 決定事項（2026-11-05 使用者確認）

1. **Q1** 生涯畢業的狗能力固定，不能再訓練、不能重置；「領養＋20 次訓練」路線照舊。
2. **Q2** 生涯學到的技能永久有效（只限生涯畢業的狗），犬舍技能池的 30 分鐘規則不變。
3. **Q3** 一趟生涯 24 回合（3 年 × 8 回合，3 場目標賽）。
4. **Q6** 犬種自由選，祖先只給因子。
5. **Q5** 紅因子第一版只做跑法適性（使用者看過建議、未提出異議），不加地形適性。
6. **Q4** 生涯中的比賽能不能下注：未特別詢問，先照建議「不能下注」，試玩後再調。

## 5. 第 1 步完成：計算核心＋平衡模擬（2026-11-05）

- `static_src/saigo_career.js`（`window.PriTestSaigoCareer`）：建立、訓練（5 種、訓練等級 1〜5）、休息、外出、失敗與受傷、31 個事件（含 8 個二選一）、目標賽、自選比賽、技能商店（生涯技能表＋提示折扣）、畢業資料。所有擲骰由 `c.seed`＋計數器決定（重新整理不能重擲）。還沒接到畫面，頁面也還沒載入。
- 數值（實測後的版本）：訓練主能力 4.6／次能力 1.7（× 訓練等級 +10%／級 × 調子）；體力消耗 16〜22、休息 +50（15% 只 +30）、外出 +15 與調子 +1；比賽隨機 2 項 +1.5〜3；每項上限 70。
- `tools/saigo_check/career_sim.js`：自動玩家跑 500 趟（約 7 秒）。結果：

| 項目 | 自動玩家（體力 < 45 就休息） | 貪心玩家（體力 < 12 才休息） |
| --- | --- | --- |
| 訓練加成合計 | 137（犬舍 20 次訓練的狗＝95，約 1.45 倍） | 128 |
| 每趟失敗／受傷 | 0.01／0 | 0.86／0.28 |
| 目標賽（新手前 3／一般前 3／重賞第 1） | 93%／93%／60%（全部達成 52%） | 94%／88%／55%（46%） |
| 評分 | S 14%、A+ 24%、A 34%、B+ 17%、其餘 15% | S 9%、A+ 22%、A 29%… |

- 調整過程：一開始主能力 7／次能力 2.5 時是犬舍狗的 1.92 倍、重賞勝率 80%，降到現在的數值。
- **發現（要使用者決定）**：關卡賽現有的 CPU 本來就偏弱——只練 20 次（速度、耐力各 10 次）的犬舍狗，一般戰勝率約 75%、新手戰約 95%；生涯畢業狗一般戰約 92%、重賞約 62%。計畫中的「關卡賽 CPU 依玩家實力補強」會同時影響現有玩法（犬舍狗也會變難贏），第 2 步動工前要確認：
  - A：關卡賽 CPU 一律補強（同真賽狗 NPC：貼近出賽玩家最強的狗）；
  - B：只在有生涯畢業狗出賽時補強；
  - C：維持現狀（生涯狗本來就該比較強）。
- `core_check.js` 新增第 10 項（確定性、失敗率邊界、目標賽沒達成就結束、受傷、二選一事件、技能商店價格／折扣／欄位、能力上限、畢業資料）。
