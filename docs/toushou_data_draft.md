# 東正小遊戲（toushou）資料擬稿 v1（審核用）

狀態：擬稿，待使用者審核。確認後補上日文並轉成 `static_src/toushou_data_*.js`。

撰寫方針：
- 起始股價 100（只是起點，可超過）。**簡介只寫優點**，股東再放消息往下扣或往上推。
- 標的欄位：名稱／類別／簡介 `summary`／特徵 `tags`（2～3）／消息切入點 `hooks`（3）。
- 消息牌：通用牌＋類別專屬牌；`{target}` 會代入標的名稱。tone：▲利多、▼利空、◆中立。
- 每類 6 個標的、6 張專屬牌；共 11 類、66 個標的、66 張專屬牌、12 張通用牌。
