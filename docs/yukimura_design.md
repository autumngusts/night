# 大名幸村（yukimura）設計說明

2026-11-05 依使用者需求新增。類倖存者（Vampire Survivors 類型）動作遊戲，舞台是戰國時代的東北地方。

## 1. 使用者需求與對應

| 需求 | 實作 |
| --- | --- |
| 類倖存者、手機搖桿移動 | 自動攻擊；在畫面任何地方按住拖曳就是浮動搖桿（`yukimura.js` 的 `bindInput()`），電腦用 WASD／方向鍵 |
| 多人、可中途加入／退出 | 房主模擬（`yukimura_net.js`）。遊戲中開同一個網址就會加入；離線 4 秒移出戰場、角色保留在 `s.gone`，回來時恢復；房主斷線由最早加入的人從最後一份完整狀態接手 |
| 精美建模 | three.js，所有模型用基本幾何體在程式裡組出：大名武者（兜、前立 10 種、袖、草摺、指物、手持武器）、26 種敵人、13 隻首領、30 種以上場景物件。敵人與投射物合併成單一幾何體＋InstancedMesh |
| 15 分鐘存活並打倒最終魔王 | 第 5、10 分鐘中首領（掉寶箱），第 15 分鐘魔王現身，打倒即勝利。另有 5 分鐘速攻模式（不算正式攻克） |
| 10 大關卡、各有特色 | `STAGES` 的 `feat`：吹雪、地獄噴氣、南部鐵甲、河流與座敷童子、黃金鄉、生剝鬼夜襲、天狗之風、鐵砲隊、籠城砲擊、火山噴發 |
| 很多攻擊方式、技能搭配、飾品；升級三選一 | 24 種攻擊行為 × 10 藩風格；升級三選一（幸運 ≥130% 變四選一）；奧義進化、地緣、元素反應 |
| 東北地圖 ≥20 張 | 20 張（青森・岩手・秋田・山形・宮城・福島），每關 2 張 |
| 武器 ≥200 種 | 240 種（`WEAPONS`） |
| 道具 ≥500 種 | 飾品 500 種（25 種東北工藝 × 20 種能力）＋鄉土料理與道具 30 種＝530 種 |
| 大名 ≥60 位 | 121 位（`DAIMYO`）：大名 72、武將 36、女武將 8、忍者 5，各有起始武器、特性、采配（大招） |

## 2. 檔案

* `static_src/yukimura_data.js`：資料（雙語 `C(zh, ja)`）
* `static_src/yukimura_core.js`：規則與模擬（純 JSON 狀態，`step(s, dt)`、`snap()`／`unsnap()`）
* `static_src/yukimura_net.js`：Firebase 房間協定（`games/<room>/rtState/yk/...`）
* `static_src/yukimura_3d.js`：three.js 畫面
* `static_src/yukimura.js`：畫面、輸入、HUD、大廳、圖鑑、本陣強化
* `static_src/css/yukimura.css`、`site_src/i18n_yukimura.py`、`site_src/yukimura_page.py`

## 3. 系統

* **武器**：`wParams()` = 攻擊方式基礎值 × 藩風格修正 × 等級成長（`WLV`）× 能力。單發型（斬、突等）數量上限 3，超出轉成傷害。
* **奧義進化**：Lv8 ＋ 持有該攻擊方式 `evo` 能力的任一飾品 → 開寶箱時進化（傷害 ×1.7、數量 +1、範圍 +20%、冷卻 -15%）。
* **地緣**：武器的藩、飾品的工藝各屬一縣；同縣 3 件／5 件得到 `PREFS[縣].bonus`。
* **元素反應**：凍結＋灼燒＝蒸氣爆發、麻痺＋凍結＝凍雷、毒＋灼燒＝毒炎擴散。
* **采配**：擊殺累積，100% 發動大名專屬大招（11 種）。
* **本陣強化**：每局的錢存成軍資金，永久強化（含影武者復活、重抽）。
* **連斬**（2026-11-05 追加）：連續擊殺累積連斬數（3 秒沒擊殺就中斷），每 50 連斬攻擊與拾取的錢 +5%（最多 +30%）。
* **祠祈願**（2026-11-05 追加）：約每 100〜140 秒在附近出現祠，站在旁邊 3 秒隨機得到一種祝福（攻擊、加速、吸經驗、全隊回滿、采配、錢、無敵、幸運）。
* **秘傳**（2026-11-05 追加）：武器 Lv3 以上時升級選項會出現秘傳（`MODS`，14 種：二連、爆裂、連鎖、分裂、追尾、處刑、巨大化、疾風、貫通、吸魂、冰／炎／雷／毒之型），每把武器最多 2 個。附帶傷害不再觸發秘傳，避免無限連鎖。
* **武器搭配**（2026-11-05 追加）：同時持有特定兩種攻擊方式就發動（`SYNERGY`，16 組），給其中一把武器秘傳（不佔格）或給角色能力加成。
* **采配強化**（2026-11-05 追加）：采配每發動 3 次升一階（最多 3 階），威力 +40%／階、持續 +30%／階。
* **方向指示針**（2026-11-05 追加）：畫面外的隊友、首領、寶箱、祠在畫面邊緣顯示箭頭與距離。
* **選升級保護**（2026-11-05 追加）：跳出升級時把身邊敵人推開一小步；多人時選擇期間敵人保持距離不貼近；選完再無敵 1 秒。
* **多人**：經驗全隊共享；選升級時無敵，15 秒自動選；中途加入依隊伍平均等級補發升級次數；倒地的隊友旁邊站 3 秒可扶起。

## 4. 連線與延遲對策（2026-11-05 改版）

* **流量控制**：快照（`st`）與位置（`mv/<pid>`）的寫入在上一筆沒送完前直接跳過，網路慢時延遲不會累積。實測模擬 400ms 網路延遲 40 秒，延遲穩定在約 0.7 秒。
* **快照瘦身**：只送玩家附近（約 32 公尺）的小兵、投射物、特效，經驗珠最多 140 顆；敵人種類與投射物外觀改用數字編號；特效只送上一份快照之後新增的。只有房主一個人時不廣播。
* **完整狀態只在接手時讀取**：`fu` 不再讓每個人訂閱，接手房主時才用 `fetchFull()` 讀一次。
* **外插推算**：一般玩家依前後兩份快照算出敵人、投射物、敵彈的速度，畫面依經過時間往前推（最多 0.3 秒），看到的位置接近即時。
* **意圖序號用時間戳**：換房主後也不會重複處理或漏掉升級選擇。
* **房主交接**：房主切到背景（手機鎖螢幕、切 App）時，先寫完整狀態再把房主交給下一位（`handoff()`）；原房主回來後改當一般玩家繼續玩。
* **掛機保護**：2.5 秒沒收到某玩家的新位置（位置附遞增序號 `n`）→ 該玩家暫時無敵、敵人不追他，HUD 隊伍欄顯示 💤。
* **判定寬容**：連線玩家看到的敵人比房主晚一點，碰撞與敵彈判定半徑稍微縮小。

## 4.1 追加內容（2026-11-05）

* **天候**：約每 2.5〜3.5 分鐘變一次，持續 60 秒。雨（灼燒減半、麻痺暈眩加倍）、霧（視野縮小、敵人加速）、雷雨（天雷劈向敵人，也會在玩家附近落下紅圈）。
* **懸賞首**：約每 2 分鐘出現金色的懸賞敵人（💰 指示針），30 秒內打倒得到大寶箱與大量錢。
* **陣形**：多人時 5 公尺內每有一名隊友，攻擊 +8%、防禦 +1（最多 3 人）。
* **連攜采配**：兩名玩家 3 秒內接連發動采配 → 兩人之間爆發「天下無雙」（大範圍傷害、兩人回復並無敵 3 秒）。

## 5. 更多遊戲性提案（未實作，供之後擴充）

1. **天下統一戰役**：東北地圖上的國盤，攻下一國得到該國的特產與家臣，最後上洛。
2. **家臣系統**：通關時隨機招募家臣（片倉小十郎、直江兼續……），出陣時帶一位，提供被動或自動攻擊的分身。
3. **每日挑戰**：固定種子＋固定大名，全世界同一張排行榜（可沿用 denshi 的每日挑戰架構）。
4. **合戰模式（PvPvE）**：兩隊各守本陣，擊殺妖怪累積的兵力定時送去對方戰場。
5. **季節輪替**：春（櫻吹雪加速）、夏（祭典：料理掉落加倍）、秋（豐收：經驗加倍）、冬（吹雪）。
6. **城郭建造**：撿到木材時可以在地上蓋柵欄、櫓、鐵砲櫓，類塔防的玩法混合。
7. **詛咒（逆鱗）**：自願背負詛咒讓敵人更強、換取更多金錢與稀有飾品。
8. **大名專屬奧義**：每位大名的起始武器進化成專屬版本（政宗的「六爪流」、幸村的「十文字槍・赤備え」）。
9. **成就與家紋收集**：完成條件解鎖家紋與兜的外觀。
10. **觀戰與重播**：沿用快照格式，把一局的快照記錄下來可以回放。

11. **合體技（連攜采配）**：兩名玩家在 3 秒內先後發動采配，觸發特殊合體技（例：伊達政宗＋片倉景綱「竜と右目」全畫面雷擊）。

## 6. 2026-11-06 追加

### 6.1 修正：選升級時仍能移動
連線時遊戲不暫停，原本 `stepPlayer()` 不管有沒有升級選項都會照搖桿移動房主自己的角色；一般玩家在快照尚未帶到 `opts` 前也能移動。
改為：有 `opts`、待選次數 `pend > 0` 或待選天命 `arcQ > 0` 時不移動（`yukimura_core.js` 與 `yukimura.js` 的 `onFrame()`），升級視窗開著時也不移動。

### 6.2 新模式「天下布武」（使用者：本陣強化帶進新模式、參考更多倖存者遊戲、天賦樹式新本陣、形狀不同的符文拼進固定格子、新幣別）

| 系統 | 內容 |
| --- | --- |
| 本陣強化帶入 | 原本的 `D.META` 照樣套用（`sortieMeta()` 把 `progress().meta` 和 `tk` 一起放進 `P.meta`），錢也照樣存進軍資金 |
| 新幣別「軍功 🎖️」 | 精英 30% +1、懸賞首 +5、中首領 +8、魔王 +20、軍令達成；結算＋存活分鐘×3＋擊殺÷150＋勝利獎勵，乘逆鱗與「論功行賞」。5 分鐘速攻 ×0.4 |
| 軍略樹（天賦樹） | 30 個節點、4 條分支（武／守／智／財）＋符文格擴張；前置節點任一已點才能點；可全額重置 |
