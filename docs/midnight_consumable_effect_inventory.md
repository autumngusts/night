# midnight 消耗品一覽與使用動畫整理（2026-09-21）

使用者需求：「所有消耗品幾乎要有使用動畫與特效等，先整理物品與種類出來」。
本文件是第一步——把 `static_src/consumables.js` 的 18 項道具依規則書分類、對象、
midnight 目前實際套用的效果（`static_src/midnight.js` の `applyMidnightConsumableEffect()`）
與**現有動畫**逐項列出，並在最後提出動畫分組的草案，供下一步設計時逐組確認。

資料來源：

* 品名／對象／使用次數：`static_src/consumables.js`（規則書 203〜204 頁轉錄）。
* 分類：同檔案 `DETERMINE_TABLE`（消耗品決定表的三個列：基本道具／投擲類道具／調香瓶類消耗品）。
* midnight 效果：`applyMidnightConsumableEffect()`（2026-09-12 使用者逐項給定的即時制數值）。
* 現有動畫：`MIDNIGHT_CONSUMABLE_THROW_STYLE`／`triggerConsumableThrowEffect()`（丟擲物飛向敵人立繪＋命中刀光）。

## 1. 道具一覽

「獲得數」＝`consumableAcquireCount()`（基本 2 個，使用次數 3 的道具 3 個；鑰匙類 1 個）。
「現有動畫」欄是 2026-09-21 動畫批次**實作前**的狀態（**丟擲**＝從畫面下方飛向敵人立繪的 emoji 丟擲物＋落地時的命中刀光；**無**＝只有 toast 文字與行動泡泡），實作後的狀態見 §2。

## 2. 使用動畫（2026-09-21 使用者逐項規格，已實作）

實作位置：`static_src/midnight.js` の `triggerConsumableUseEffect()`（使用當下的一次性動畫）、
`updateConsumableBuffVisuals()`（持續型效果的常駐視覺，每幀依 `_xxxUntil` 判斷、到期自動消失）、
`triggerConsumableThrowEffect()`（投擲）；樣式在 `static_src/style.css`「消耗品使用時的卡片動畫」
「持續型消耗品效果的常駐視覺」兩段。

通則：**持續型效果後放的直接覆蓋前一個，時間不相加**（各 `_xxxUntil` 一律 `= now + 10s` 覆寫；
溫石對自己的持續回復重用時移除舊條目，隊友身上的條目不覆蓋）。

| 道具 | 使用當下 | 持續時間內（10 秒） |
| --- | --- | --- |
| 勇者的肉塊 | 消耗品格上升符號 | 攻擊／戰技鍵背景上升符號（金） |
| 龜首漬 | 消耗品格上升符號＋體力條閃光 | — |
| 星光的碎片 | 格子外水晶碎片飛散＋FP 條閃光 | — |
| 苔藥 | 治癒粒子（✚）＋卡片綠光；自身蓄積列上該異常徽章「消散」 | — |
| 塗脂 | 屬性符號粒子 | 塗了那一側的攻擊／戰技鍵背景屬性符號＋屬性色內光；武器卡片鍍色（盾脂為藍） |
| 溫石 | 治癒粒子 | 自身與對象席位卡片暖色光暈＋上升粒子 |
| 投擲短劍／蒼火的投擲刀／骨毒投擲箭 | 從消耗品卡片直線飛向敵人立繪＋自轉（刀類），落地命中刀光 | — |
| 扇投暗器 | 刀類飛行，落地 10 段連閃 | — |
| 投擲壺 | 拋物線飛向敵人（瓶壺類），落地依取得時屬性的爆裂 | — |
| 火花之香／毒之噴霧／酸之噴霧 | 瓶壺類飛行＋屬性爆裂（酸為白） | 酸：迴避／防禦鍵背景盾牌脈動 |
| 高揚之香 | 消耗品格上升符號 | 右下／左下所有操作鍵背景上升符號（橘）；全部席位卡片亮起 |
| 鐵壺之香藥 | 卡片藍盾光 | 迴避／防禦鍵背景盾牌脈動；自身席位卡片與「角色」鍵鐵化色調 |
| 石劍鑰匙／鍛造石 | 無（持有即生效） | — |

塗脂的屬性：跟投擲壺同一套規約，取得時記在 `c.consumableAttributeTags[instanceId]`（獎勵有指定就用
指定的），使用時直接塗上、不需選擇；沒有記錄時維持預設「炎」。卡片／角色面板顯示為「塗脂（雷） x2」。

## 3. 現有可重用的特效機制

* `#midnight-consumable-throw-effect`（丟擲物）、`#midnight-enemy-hit-effect`（命中刀光）、
  `#midnight-enemy-ailment-effect`（屬性光暈）、`#midnight-affix-rider-effect`（詞條追擊）：
  都是疊在敵人立繪上的獨立 overlay，可同時播放。
* `.midnight-cell-badge`／`.midnight-cell-orbit`／`.midnight-action-flash`：浮在操作格上方的
  浮標／環繞星體／閃字，可作為「自身用道具」的卡片回饋。
* `#midnight-flask-using-badge`＋`#midnight-flask-read-fill`：聖杯瓶「使用中」浮標＋讀條，
  分組 C 的限時強化可直接套用同款。
* `showActionFlash()`／`broadcastCombatActionBubble()`：所有消耗品已經會在行動泡泡顯示品名。
