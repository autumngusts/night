* 在 PriTest 新增遊戲「神前鍛刀對決 katana master」。

## 1. 流程

1. **鍛刀（forge）**：13 道工序。同一裝置輪流，「每道工序全員各做一次」（`Core.currentForger`：進度最少者優先，同進度依座位）。換人時顯示交接畫面。
2. **神前審查（judge）**：地鐵／刃文（整體淬火的刀種改為「熱處理」）／姿／健全／研磨，各 20 分，共 100 分，等級：神品 ≥90、上上作 ≥78、上作 ≥65、良作 ≥50、普通作 ≥35、鈍刀。
3. **開刃試鋒（cut）**：五種目標（蓆一捲、三捲、青竹、五捲、鐵盔）依序，每人每目標一次刃筋時機小遊戲，可放棄目標。損傷（耐久）帶進互擊。
4. **對刀（clash）**：陀螺式圓形場地即時對刀，打到只剩一把（見 §7）。人數不足兩把時可加入對手刀（見習、村中鍛冶、神前奉納刀），也可從刀鞘拔刀參戰（AI 操作）。
5. **總結（end）**：總合 = 審查分 + 試斬分 × 2 + 互擊名次加分（15／8／4）。

## 3. 冶金模型（`katana_core.js`）

全部以文獻上的經驗式或物理式計算，**只有標明「校正值」的常數是依實務結果調整**。

| 現象 | 模型 |
| --- | --- |
| 脫碳 | 碳在沃斯田鐵中的擴散係數 `D = 2.3e-5·exp(−148 kJ/RT)`；每次加熱的脫碳比例 `4/h·√(Dt/π)·保護倍率`（鋼坯 15mm、每次 100 秒、每折 3 次加熱、灰泥保護 0.55）。 |
| 氧化損失 | 拋物線氧化，`exp(−Q/2RT)`、Q = 165 kJ；以「1300℃、有保護時每次 2.7%」校正。 |
| 沸燒上限 | Fe–C 固相線（1538℃ → 0.17% 1495℃ → 2.11% 1148℃ 的二次近似，Ni 每 1% −3℃）。鍛接窗口＝固相線 −150〜−35℃，超過固相線 −15℃ 即燒損。 |
| 層間均質化 | 折返後層厚 λ = 15mm／層數，與擴散距離比較，碳的不均（consistency）指數收斂。 |
| 熱脆 | S > 0.012% 且 Mn/S < 4 時，在 950〜1150℃ 鍛打會因 FeS 晶界熔化而開裂。 |
| 變態點 | Andrews：`Ac1 = 723 − 10.7Mn − 16.9Ni + 29.1Si + 16.9Cr + 6.38W`；`Ac3 = 910 − 203√C − 15.2Ni + 44.7Si + 104V + 31.5Mo + 13.1W`；Acm 依 ES 線（每 1%C 約 314℃）。 |
| 淬火適溫 | 亞共析：Ac3 + 20〜60℃；過共析：Ac1 + 20〜60℃。 |
| 沃斯田鐵化 | 低於 Ac1 不淬硬；亞共析在 Ac1〜Ac3 之間依槓桿定則殘留肥粒鐵（焼きむら）；過共析的溶入碳量隨溫度沿 Acm 線增加，其餘為未溶碳化物。 |
| 淬透性 | Grossmann 理想臨界直徑 `DI = 0.29√C × 晶粒度係數 1.09^(7−G) × Π(1 + k·合金)`（Mn 3.333、Si 0.7、Ni 0.363、Cr 2.16、Mo 3.0、W 0.5、V 1.73）。臨界直徑 `Dc = DI·H/(H+0.8)`。 |
| 淬火強烈度 H | 鹽水 1.9、冷水 1.25、溫水 0.95、熱水 0.6、油 0.3。土層倍率：薄 ×1.5（破壞蒸氣膜、加速冷卻）、中 ×0.6、厚 ×0.25。 |
| 截面 | 刃口厚 1.2mm，往鎬（或雙刃的中脊）線性增厚到「重」。楔形斷面以 1.2t 為等效圓棒直徑。截面取 21 點計算。 |
| 麻田散鐵 | 冷卻分率 `1/(1+exp((1.2t − Dc)/(0.2Dc)))` × Koistinen–Marburger `1 − exp(−0.011(Ms − 浴溫))`；Ms 由 Andrews `539 − 423C − 30.4Mn − 17.7Ni − 12.1Cr − 7.5Mo − 7.5Si`。其餘為殘留沃斯田鐵與波來鐵。 |
| 硬度 | 麻田散鐵：Hodge–Orehoski 多項式；各相以 HV 線性混合再換回 HRC；未溶碳化物最多 +3。 |
| 刃文 | 硬化邊界＝由刃口往內第一個麻田散鐵 < 50% 的位置。清晰度＝（麻田散鐵 75%→25% 的過渡寬度越窄越好）×（邊界與土線吻合度）×（1 − 刀背麻田散鐵／刃口麻田散鐵）。 |
| 淬火反り | 麻田散鐵變態膨脹 `ΔV/V ≈ 1.68·C %` 作為固有應變，以樑理論求曲率 `κ = Σε(y−yc)t / Σ(y−yc)²t`，弓高 `κL²/8`。再乘**塑性放大 2.5（校正值**：淬火初期刃先收縮、高溫刀背降伏，彈性解只有實際約四成；依「淬火約產生 1〜1.5cm 反り」校正）。雙刃對稱 → 0。 |
| 晶粒 | 鍛打再結晶 6 + 精準度×1.2（沸燒過高變粗）；正常化 1/2/3 次 +1.2/+1.8/+2.1；淬火過熱每 35℃ −1；過共析有未溶碳化物時 +0.5。 |
| 淬裂 | `0.018 × H^1.6 × (Cd/0.6)² × 粗晶 × 低 Ms × 刃文種類 × 刀背也淬硬 ×1.5 × 既有瑕疵 × (1+5P)`。 |
| 回火 | 溫度來自回火色小遊戲（數值）。Hollomon–Jaffe `P = T(K)(20 + log t)`；P > 8200 起每 1 降 0.003 HRC（P > 11500 後 0.0018）。230℃ 以上殘留沃斯田鐵分解。 |
| 韌性 | `110 − 1.5HRC + 回火恢復 − 回火麻田散鐵脆性（230〜400℃，谷底約 315℃）+ 3(G−7) − 18(Cd−0.6) − 10RA − 0.35鐵滓 − 150P + 3Ni + 刀背未淬硬加成`，再與心鐵（低碳肥粒鐵）依造込的心鐵比例複合。 |

這些是有文獻依據的近似，不是有限元素模擬；刀匠實務仍有許多無法量化的因素。

### 3.1 會自然出現的現象（測試有覆蓋）

* 玉鋼幾乎不含 Mn/Si，淬透極淺 → 刃文由土層控制、刀背不硬；但寬幅刃文（丁子、皆燒）要硬化到土線需要更急的淬火（鹽水），淬裂風險隨之上升。
* 1060（Mn 0.75）、青紙（Cr・W）淬透深 → 厚土下也局部淬硬，刃文糊掉、刀背變硬。
* 過共析鋼加熱過頭 → 溶入碳增加、Ms 下降、殘留沃斯田鐵增加、晶粒粗化、淬裂風險升高。
* 雙刃劍兩側對稱 → 淬火不產生反；彎刀的深彎、廓爾喀刀的內彎要靠火造。
* 烏茲鋼超過 Acm 或折返 → 碳化物溶解，紋路消失；S 多、Mn/S 低 → 熱脆。
* 鍛太多次 → 脫碳到淬不硬；不撒灰泥 → 脫碳、氧化都變多。

## 5. 審查

* **地鐵**：鐵滓 7、含碳是否在範圍 4（烏茲鋼範圍 1.2〜1.8%），再依紋路系統加分：
  * 地肌（玉鋼系）：地肌美觀 3〜4 ＋ 均質度 2 ＋ 卸鐵 1；折返 > 18 次 −3、< 10 次 −2。
  * 無紋（現代鋼）：日本刀 +1（並評「看不到地肌」），異國刀劍 +4。
  * 大馬士革：層數接近 200 層最佳（最多 +5）；做成日本刀 −2。
  * 烏茲：紋路保留 +6；做成日本刀 −1。
  * 流星刀：3.5 + 傳說 1 + 均質度。
  * 日本刀用非傳統和鋼：較真模式 −3（神前視為偏離正統）；表演模式不扣分（趣味）。大馬士革、烏茲做成日本刀的 −2／−1 也只在較真模式。
* **刃文**（差異淬火刀種）：`刃文潛力 × (0.4 + 0.6·清晰度) × (0.4 + 0.6·硬度符合度) + 足 0.5`；未置土僅依硬度給最多 6。
* **熱處理**（整體淬火刀種）：`14·硬度符合度 + 6·刃背均勻度`。
* **姿**：刃長、彎度、身幅、重是否在該刀種範圍，斷面／切先／反的位置是否合該刀種。
* **健全**：20 − 各瑕疵扣分。
* **研磨**：研磨分 × 14 ＋ 刃肉 1 ＋ 莖 2 ＋ 有銘 3。

## 6. 試斬

沿用 `stats()` 算出的硬度、韌性、鋒利、重量、耐久。試斬：`鋒利 × (0.55 + 0.45·刃筋) + 重量 × 8 ± 8 ≥ 目標難度` 即斬斷；硬脆的刀打硬目標易刃崩、軟的刀易彎，有淬裂的刀砍鐵盔可能折斷。

### 7.2 命名與覺醒招式

鍛完進入審查時（`applyStep` 把 phase 改成 judge 的那一刻），`Core.awaken()` 依種子決定每把刀的覺醒招式（`blade.special`，可為 null）。

招式全部是**資料驅動**（`D.SPECIALS`，35 種，分三組 `D.SPECIAL_GROUPS`）：

* `req`：覺醒條件，由 `Core.specialCandidates()` 的 `meetsReq` 通用判定（HRC／鋒利／韌性／質量／刃長／反り／身幅／重ね／總評／各項分數／瑕疵數／刃文清晰度、刀種／材料／淬火介質／刃文／反り型／造込み清單、波刃；`any` 為「其中一組符合即可」）。
* `fx`：效果，由 `katana_arena.js` 的 `activateSpecial` 以通用積木實作：`buff`（倍率、無敵、穿透、閃避、觸及、回復、反噬、反彈、吸引、接觸效果 `onHit`…）、`strike`（對最近／最強／最弱／全體斬擊，可瞬移、麻痺、擊退、毒、解除強化、多段）、`meteor`、`heal`、`cleanse`。新增招式只要加資料，不需改對刀場程式。

### 7.3 對刀場（`static_src/katana_arena.js`，`window.PriTestKatanaArena`）

固定步長 1/60 秒的確定性模擬（種子＋玩家放牌時間點決定結果）。場地半徑 100，碗形重力 `a = −0.32·r`、摩擦 0.55/秒。

* **刀 → 陀螺參數**（`profile(snap)`）：耐久＝`stats().integrity`；攻擊 `0.5 + 鋒利/100 + max(0, HRC−55)/40`；防禦 `0.6 + 韌性/100 + max(0, HRC−50)/100`；觸及半徑 `8 + 刃長/7`；推進力 `30·打法倍率 / 質量^0.35`。
* **打法**：質量 < 0.75 持久型；韌性 ≥ 鋒利+10 或質量 ≥ 1.6 防禦型；鋒利 ≥ 韌性+8 攻擊型；其餘均衡型。影響推進力、勢い衰減與追擊力。
* **特性**：雙刃（分開時補一刀）、拖斬（反り ≥ 20：僵持 ×0.7、傷 ×1.2）、刺擊（直的細雙刃：撞擊傷 ×1.5）、重擊（≥ 1.5kg：彈飛 ×1.5）、波刃（多削勢い）、硬而脆（HRC ≥ 61：崩刃）、偏軟（HRC < 52：彎曲變慢）、帶淬裂（相接時 5% 折斷）。
* **碰撞**：圓相交且相對法向速度 ≥ 9 →「刀刃相接」：鎖住 0.8〜2.3 秒，兩把刀刀尖相抵繞中點旋轉、持續噴火花，每秒互削 `6.5·攻/防` 耐久與勢い，往較弱的一方推；結束時依推力差彈開，該對冷卻 0.7 秒。速度不足只是擦撞彈開。撞擊瞬間另有 `相對速度·0.045·攻/防` 的傷。
* **退場**：耐久 0＝折斷；勢い 0＝力竭（自然衰減約 90 秒、相接與撞牆會加速）。剩一把即結束；15 回合（60 秒）到時以 `耐久比·0.7 + 勢い·0.3` 判定。
* **招式卡**：牌庫＝基本 13 張（踏進×2、守勢×2、調息×2、看破、一閃、居合、楓葉斬、開花斬、落櫻斬、吹雪斬）＋打法追加 2 張，手牌 3 張、等待區 2 格。放進等待區後在 `目前回合 + 1 + wait` 的回合交界發動（踏進／守勢／調息／看破 wait 0，一閃／居合／楓葉斬 wait 1，覺醒招式 wait 2 且每場一次）。回合交界補牌。AI：每回合 55% 機率出牌，耐久 < 70% 或第 4 回合後優先放覺醒招式。
* 鍛刀局內的對刀：試斬剩下的耐久帶入；結果（`placing`）沿用總結的名次加分（15／8／4，只算玩家）。對刀場狀態放在 `ui`，不存檔（重新整理會重打）。
