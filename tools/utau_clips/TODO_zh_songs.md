# 待製作：華語追加曲目（2026-10-19 使用者勾選）

使用者從候選清單中挑出、之後要在**另一台裝置**製作的華語歌（共 33 首）。
目前都**還沒**加進 `static_src/utau_songs.js` 與 `songs.json`。

## 製作步驟

1. 在 `static_src/utau_songs.js` 的華語區塊加入 `S(年份, "歌名", "歌手")`。
   - 年份與分類是建議值，加入前請再確認。
   - 分類：`pop`＝流行，`screen`＝影視（日劇・電影・電視劇主題曲）。
2. 用 `find_urls.py` 找 YouTube 官方音源，寫進 `songs.json`（確認 `start` 片段）。
3. 華語歌要做 `zh_sing`／`ja_sing` 的話，照 `README.md` 的「中文版」「日文版」流程準備歌詞。
4. `build_pack.py` 重做題庫包。
5. 做完的歌從本清單刪掉（或打勾），全部完成後刪除本檔。
