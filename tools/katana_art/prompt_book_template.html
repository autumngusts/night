Katana Master 生圖手冊

每張卡片都是一張要交給 ChatGPT 的圖：先上傳參考圖（刀種才有），再貼上提示詞。提示詞是英文的，照原樣貼上就好，不需要翻譯或修改。

怎麼做一張圖

  1. 開一個新對話同一分組（例如日本刀）在同一個對話裡連續做，畫風比較一致。
  2. 上傳參考圖刀種卡片左邊的白底圖。按右鍵「另存圖片」，或直接用 repo 裡 docs/katana_art/ref/ 的同名檔案。特效與切入圖不用參考圖。
  3. 複製提示詞並送出按卡片上的「複製提示詞」，貼進 ChatGPT 送出。不要另外加說明，提示詞已經寫好尺寸與背景。
  4. 對照檢查清單每個分頁上方有要檢查的項目。不符合就回覆：Redo it. The guard must be exactly at the center. 這種一句話的修正。
  5. 下載並改檔名存成卡片下方寫的檔名，放到對應資料夾。背景是綠色的話，先去背再放。

背景透明做不出來時：提示詞已經要求「不能透明就用純綠 #00FF00 背景」。拿到綠底圖之後用去背工具（Photoshop 的「選取 › 顏色範圍」、remove.bg 等）把綠色去掉，存成透明 PNG。

用 API 產圖時：gpt-image-1 可以直接指定 size 與 background: "transparent"，數值照卡片上的標籤填，提示詞照貼。

遊戲接上的進度：俯視圖與側視圖已接上（放進資料夾、在 katana.js 的 ART_TOP／ART_SIDE 登記就會出現；還沒有圖的刀種會借已有的圖上場）。招式特效與切入圖還沒接上，先做好放著即可。見 docs/katana_art_spec.md §6。

原圖不用自己裁切：生成工具給的圖鍔不一定剛好在中心。原圖先放在 photo/tmp/katana/（例如 tachi_upon.png、tachi_side.png），交給 Claude 整理成規格位置再放進遊戲。
